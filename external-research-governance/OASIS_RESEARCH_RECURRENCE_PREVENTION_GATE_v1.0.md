# OASIS Research Recurrence Prevention Gate v1.0

Korean: OASIS 연구 재발방지 게이트 v1.0
Status: External audit layer only

## 1. Position

This gate is outside the OASIS Integrated Paper System, outside the mathematical model, and outside production code.

It decides only whether a proposed research task is sufficiently distinct, uncontaminated, and necessary to begin.

It does not decide what result should occur.

## 2. Mandatory pre-start questions

Before any new experiment, mathematical revision, or implementation validation:

1. Has the same question already been tested?
2. Has the proposed mechanism already been falsified or retired?
3. Is the proposal merely renaming a legacy mechanism?
4. Does an existing result already answer the question at the required evidence level?
5. Is there a genuinely unresolved question?
6. Does the design reintroduce known contamination?
7. Is a fresh kill-search required?

If no unresolved question remains, the new experiment must not run merely to obtain another favorable result.

## 3. Known recurrence hazards

The following must be flagged when reintroduced without a new, independently justified reason:

- `danger = Responsibility Axis`
- fixed threshold treated as an OASIS principle
- non-current relation treated as deletion
- relational reappearance treated as guaranteed behavioral change
- unrealized possibility preserved as an independent parallel future
- experimenter-supplied action menu treated as native Possibility Composition
- NoRelation whole-field removal used as proof of OASIS superiority
- contaminated Blind Historical v2 used as paper evidence
- future information, target outcome, success label, or hidden reward entering current judgment
- past favorable outcomes encoded back into a new harness

## 4. Contamination firewall

This gate may read prior research.

The experiment under evaluation must not receive this gate's expected conclusion as input.

Allowed:
`prior research -> researcher-side exclusion / audit / duplication check`

Prohibited:
`prior research -> environment design that forces the expected OASIS behavior`
`prior research -> OASIS reward or candidate ranking`
`prior research -> preferred relation cue`
`prior research -> success criterion chosen after seeing prior favorable results`

## 5. Output classes

- `PROCEED_NEW_UNRESOLVED_QUESTION`
- `PROCEED_REPLICATION_WITH_EXPLICIT_JUSTIFICATION`
- `PROCEED_STRONGER_COUNTEREXAMPLE`
- `BLOCK_REDUNDANT`
- `BLOCK_RETIRED_MECHANISM`
- `BLOCK_CONTAMINATION_RISK`
- `BLOCK_EXISTING_EVIDENCE_SUFFICIENT`

These outputs govern research start only. They are not experimental outcomes.

## 6. Evidence update rule

After a new study, never overwrite history.

Record:
- prior evidence state;
- new conditions;
- new observation;
- why it agrees or differs;
- changed evidence classification, if any.

Positive, negative, null, contaminated, and implementation-mismatch results all remain in the genealogy.

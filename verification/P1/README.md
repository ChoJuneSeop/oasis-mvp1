# OASIS P1 독립검증 — 합성 구조 반증실험

## 목적

P1의 구현이 다음 세 조건을 실제로 만족하는지 공격적으로 검사한다.

1. 동일한 과거 완결 경험 집합 E와 동일한 현재 조건 X를 유지한 채 관계이력 R만 바꾸면 가능성 분포가 달라지는가.
2. 동일한 E, X, R을 유지한 채 참여상태 P만 바꾸면 가능성 분포가 달라지는가.
3. 과거 관계이력 R이 현재 참여상태 P의 효과 자체를 바꾸는가. 즉 참여정도가 독립적인 고정 가중치가 아니라 관계과정과 결합되어 형성되는가.

## 비교군

- `fixed`: 과거 경험에 고정 가중치만 부여한다.
- `similarity`: 현재와의 단순 유사도만 사용한다.
- `no_history`: 현재 참여상태는 사용하지만 관계이력을 제거한다.
- `oasis`: 현재 맥락, 관계이력, 현재 참여상태와 이들의 비선형 상호작용으로 과거 완결 경험의 재활성화 정도를 계산한다.

## 주요 측정값

가능성 분포 간 차이는 Jensen-Shannon divergence(JSD)로 측정한다.

- `relation_history_sensitivity`: 관계이력만 바꾼 대응쌍의 JSD
- `participation_sensitivity`: 참여상태만 바꾼 대응쌍의 JSD
- `history_x_participation_interaction`: 관계이력이 달라질 때 참여상태 변화의 효과도 달라지는지 측정

## 반증 조건

다음 중 하나라도 실패하면 이 구현은 P1 구조를 만족한다고 판정하지 않는다.

- OASIS에서 관계이력 변화 효과가 대부분의 반복실험에서 수치적으로 0이 아님
- 관계이력을 제거한 비교군에서는 관계이력 효과가 사라짐
- OASIS에서 참여상태 변화 효과가 대부분의 반복실험에서 수치적으로 0이 아님
- OASIS에서 과거 관계이력이 현재 참여 효과를 조절함
- `no_history` 제거실험에서는 위 상호작용 효과가 사라짐

`EPS=1e-12`는 부동소수점 수치적 0을 구분하기 위한 기준일 뿐 OASIS의 의사결정 임계값이 아니다.

## 실행

```bash
python verification/P1/p1_structural_falsification.py
```

기본 설정은 seed `20260905`, 1,000회 반복이다. 결과는 `verification/results/p1_latest.json`에 기록된다.

## 해석 제한

이 실험은 **합성 구조 검증 / 명세 일관성 검증**이다. 코딩된 구조가 주장한 성질을 보존하는지 확인할 뿐, 현실 세계에서 P1이 참이라는 경험적 증거가 아니다. P1의 외부 실증 검증은 별도 데이터와 독립 baseline으로 이어서 수행한다.

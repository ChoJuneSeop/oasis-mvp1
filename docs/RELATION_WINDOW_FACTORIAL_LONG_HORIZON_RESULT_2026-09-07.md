# OASIS 관계장 시간창 2×2×2 장기 귀속 실험 — 2026-09-07

## 지위

- 기존 canonical 실험을 대체하지 않는 장기 확장 본검증이다.
- production `relation-field.js`는 수정하지 않았다.
- 테스트 브라우저 컨텍스트에서만 canonical 소스를 변환했다.
- 기존 기준 `18/80/1200`, browser-world 4,000틱, open-possibility 520틱은 compatibility guard로 보존 확인했다.
- Stage 30의 미실현 가능성 인과효과는 본 실험 범위가 아니며 기존 미검증 판정을 유지한다.

## 목적

이전 `18/80/1200` 대 `180/800/12000` 비교는 세 시간창이 동시에 바뀌어 차이의 원인을 분리할 수 없었다. 따라서 아래 세 요인을 완전요인으로 분해했다.

- R: 관계이력 참조창 18 ↔ 180
- E: episode 보존창 80 ↔ 800
- A: 재활성화 연령 1,200 ↔ 12,000틱

총 2×2×2 = 8조건을 모두 120,000틱 실행했다.
모든 조건은 동일한 결정론적 `env(tick)`을 받았다. 단, 각 조건의 선택 이후 내생 궤적은 달라질 수 있다.

## 기술적 귀속

완전요인 기술적 대비값은 통계적 추론이 아니라 단일 결정론적 세계에서의 서술적 효과이다.

### R — 관계이력 18→180

가장 큰 양의 변화는 관계수, 참여변화, 선택변화, 구조확장에서 나타났다.

- 관계수 주효과: +138.25
- 활성: +395
- 참여변화: +224
- 선택변화: +192.25
- 구조확장: +264.5
- 필드나선: +33

현재 구현에서는 장기 결과의 상당 부분이 단순 보존기간보다 `현재 관계를 구성할 때 몇 개의 최근 관계를 재조합 대상으로 참조하는가`에 민감하다.

### E — episode 80→800

A가 1,200으로 고정된 상태에서 E 단독 변경은 B와 비교해 선택변화·참여변화·구조확장을 바꾸지 않았다.

B와 E:
- 관계수 805 = 805
- 참여변화 722 = 722
- 선택변화 1,377 = 1,377
- 구조확장 1,612 = 1,612
- 필드나선 37 = 37

즉 단순히 더 많이 저장하는 것만으로는 장기 관계효과가 자동 발생하지 않는다.

### A — 재활성화 연령 1,200→12,000

A 단독 변경은 현재 판단 구조를 크게 바꿨다.

B → A:
- 활성 1,866 → 2,653
- 참여변화 722 → 1,164
- 선택변화 1,377 → 1,522
- 구조확장 1,612 → 1,804
- 필드나선 37 → 6

따라서 더 오래된 관계를 현재화할 수 있게 하는 것은 활동량을 늘리지만 나선 발생을 자동으로 증가시키지 않는다.

## >1,200틱 관계의 현재 직접기여 검증

A=12,000 조건에서는 의사결정 시점에 현재 상태를 그대로 고정한 뒤, 동일한 상태를 두 번 평가했다.

1. 실제 확장조건: 12,000틱까지 재활성화 허용
2. 반사실 조건: 즉석에서 1,200틱으로 제한

이 평가는 실현 궤적을 수정하지 않고 후보·리더·선택 판단서명만 비교했다.

### A 18/80/12000

- >1,200틱 episode가 활성되는 의사결정: 1,598회
- 최근 episode로 대체되지 않는 오래된 활성관계가 있는 시점: 932회
- 반사실 probe: 932회
- 판단서명 차이: 171회
- 선택 차이: 84회
- 실제 선택과 확장조건 선택이 일치하면서 1,200 제한 시 다른 선택: 80회
- 최초 판단서명 차이: 2,900틱
- 최초 선택 차이: 3,304틱
- 관측된 오래된 활성 episode 최대연령: 11,723틱

최초 선택 차이 사례:

- tick 3,304, blue 파티
- 확장조건 선택: road
- 1,200틱 제한 반사실 선택: lake
- 후보집합은 동일
- 리더도 동일
- 차이는 오래된 관계가 현재 선택 순위에 참여하면서 발생

따라서 현재 구현을 확장한 동일 상태 내에서는 `1,200틱을 초과한 관계과정이 현재의 선택 계산에 직접 기여할 수 있다`는 메커니즘 수준 증거를 얻었다.

단, 이것은 역사 전체를 1,200틱 조건으로 다시 실행했을 때 얻는 총인과효과와는 다르다. 이미 확장조건으로 형성된 현재 상태를 고정한 국소 반사실 직접효과이다.

## 상호작용

주요 서술적 상호작용:

- R×A 선택변화: -107.75
- R×A 구조확장: -156
- E×A 선택변화: +22.25
- E×A 구조확장: +21
- R×E 활성: +284

따라서 세 창은 단순 가산관계가 아니다. 특히 R을 넓히면 episode 생성밀도가 증가해 E 및 A의 효과가 다시 달라진다.

## OASIS 관점 판정

이번 결과는 `오래 기억할수록 좋다`를 지지하지 않는다.

더 정확한 구조는 다음과 같다.

과거 관계과정 보존
→ 현재 흐름과의 관계 성립 여부
→ 현재화 가능범위
→ 참여/순위/선택 계산에 실제 기여하거나 기여하지 않음
→ 결과 이후 다음 구조 변화

관계가 오래 남아 있어도 현재 흐름에서 의미가 없으면 현재 선택을 바꾸지 않는다. 반대로 1,200틱을 넘긴 관계라도 새로운 현재와 관계가 성립하면 현재 선택 계산에 다시 참여할 수 있다.

## 현재 판정

### 확인

- production 관계장 파생 구조에서 1,200틱을 넘긴 과거 관계가 현재 판단서명에 직접 기여하는 경우가 존재한다.
- 그 영향은 즉시 고정되지 않고 최초 선택 차이가 3,304틱에서 관측됐다.
- 더 많은 저장량 자체는 효과의 충분조건이 아니다.
- R/E/A는 서로 상호작용한다.
- 관계활성 증가와 필드나선 증가는 동일 개념이 아니다.

### 미확인

- 여러 독립 세계/시드에서도 동일 분포가 재현되는가.
- 장기 관계 직접기여가 자연환경·외부 데이터에서도 나타나는가.
- O1 순서차이 자체가 production 본체에서 장기 재활성화의 원인이 되는가.
- 역사 전체를 되감은 총인과효과 크기.
- 미실현 가능성 자체의 후속 현실 인과력(Stage 30).

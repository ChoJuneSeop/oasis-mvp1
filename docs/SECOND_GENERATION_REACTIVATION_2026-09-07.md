# OASIS 2세대 관계 장기 재활성화 검증 — 2026-09-07

## 1. 검증 질문

이 실험은 tick 3,595에서 실제 결과로 생성된 6개의 2세대 관계 episode를 대상으로 다음을 검증한다.

1. 관계가 현재 판단에 계속 참여하지 않더라도 보존될 수 있는가.
2. 재활성화 시점을 미리 예약하지 않았을 때, 이후 현재 흐름의 조건에 의해 다시 관계가 성립하는가.
3. 재활성화와 실제 판단 기여는 같은 사건인가, 서로 구분되는가.
4. 매우 늦은 시점의 판단 차이가 단일 관계인지, 복수 관계 집합인지 구분할 수 있는가.

범위 밖:
- 미실현 가능성 자체의 인과효과는 검증하지 않는다(Stage 30과 무관).
- 장기 기억/맥락 의존 회상 자체를 OASIS 고유성으로 주장하지 않는다.
- 본 실험의 선택적 장기보존 조건은 production 구현이 아니라 O2/O3 검증용 계측 조건이다.

## 2. 킬서치 결론

장기 과거가 후속 현재에 영향을 주는 일반 현상은 이미 여러 연구 계열에 존재한다.

- Process tensor / non-Markovian dynamics: 다중 시간 상관과 장기 환경기억을 다룬다.
- Context-dependent episodic retrieval: 현재 맥락의 재구성이 과거 기억 회상을 촉진할 수 있다.
- Event sourcing: 현재 상태만이 아니라 사건 순서를 보존하여 현재가 어떻게 형성됐는지 재구성한다.
- Long-horizon agent memory: 장기 에이전트의 경험 스냅샷과 변화하는 메모리 구조를 다룬다.

따라서 검증 필요성은 '기억이 오래 남는다'가 아니다. OASIS에서 실제로 형성된 관계과정이 비현재 구간을 거친 뒤, 사전 예약된 시간이 아니라 현재 관계조건에 의해 다시 참여하며, 그 참여와 실제 선택 기여가 어떻게 분리되는지를 확인하는 것이 목적이다.

참고:
- Keeling et al., Process Tensor Approaches to Non-Markovian Quantum Dynamics, Physical Review X 16, 020502 (2026).
- Martin Fowler, Event Sourcing (2005).
- Context-dependent episodic retrieval 계열 연구.
- 2026 long-horizon agent memory / memory trajectory 계열 연구.

## 10. OASIS 관점의 해석

이번 결과에서 가장 중요한 것은 '오래된 기억이 나중에 작동했다'가 아니다. 그것은 선행연구와 겹친다.

관찰된 구조는 다음과 같다.

실제 과거 관계과정 형성
-> 현재 관계로 참여
-> 비현재화
-> 반복적인 현재화/비현재화
-> 대부분의 현재에서는 선택 변화 없음
-> 매우 늦은 특정 현재에서 실제 판단 기여
-> 어떤 시점은 단일 관계가 지배
-> 다른 시점은 관계집합 수준의 중복적 기여

이는 '순서/과거가 다르면 곧바로 다음 현실이 달라진다'는 모델과 다르다.

더 정확한 관측 문장:

'보존된 관계과정은 미래의 모든 현재에 영향을 주는 것이 아니라, 현재 흐름과 다시 관계가 성립할 때 참여할 수 있으며, 참여했다고 해서 곧바로 선택을 바꾸는 것도 아니다. 실제 선택 차이는 훨씬 늦은 다른 현재에서 나타날 수 있다.'

## 11. 반증 및 구현상 한계

1. 현재 production은 O2의 '비현재화 != 삭제'를 완전히 구현하지 못한다.
   - 최근 80 episode 상한
   - 기본 1,200틱 활성 연령창
   때문에 충분히 오래된 관계과정은 실제로 소실될 수 있다.

2. 이번 장기 실험은 6개 cohort에 선택적 보존 예외를 둔 operator 검증조건이다.
   - 따라서 '현재 production OASIS가 107,855틱 뒤에도 자동으로 기억한다'고 주장하면 안 된다.

3. 재활성화 횟수는 현재 relevance 함수의 경계 통과에 민감하다.
   - 빈도 자체를 인과강도나 인과율로 사용하면 안 된다.

4. tick 108,777 결과는 복수 관계가 모두 동시에 필수인 순수 시너지가 아니다.
   - 관계집합 수준의 중복적 인과기여다.

5. 선행연구 때문에 장기 기억, 맥락 회상, history dependence 자체는 신규성 근거가 아니다.

6. Stage 30 실패는 그대로 유지한다.
   - 미실현 가능성의 독립적 인과력은 이번 실험에서도 주장하지 않는다.

## 12. 구현 방향

이번 실험은 production의 80개 active memory 창을 무제한으로 늘리는 방향을 지지하지 않는다.

더 적절한 구현은:

현재 active window
+ 비현재 latent process store
+ 관계 anchor 기반 index
+ 현재 흐름에서 anchor가 형성될 때만 후보 latent process 조회
+ 실제 관계조건이 성립할 때 현재화

이다.

즉 모든 과거를 매 tick 연산하는 것이 아니라, 비현재 과정은 저비용으로 보존하고 현재 관계가 형성될 때 제한적으로 다시 불러오는 구조가 O2/O3 정의와 계산비용 모두에 더 적합하다.

## 13. 판정

이번 실험에서 지지된 것:
- 실제 형성된 관계과정의 장기 보존이 후속 판단에 늦게 기여할 수 있음.
- 현재화와 실제 선택 기여는 분리됨.
- 재활성화 시점과 실제 영향 시점은 동일하지 않음.
- 단일 관계 기여와 관계집합 수준 기여가 모두 존재함.
- 즉시 다음 현실 변화가 필수라는 가설은 필요하지 않음.

아직 지지되지 않은 것:
- 모든 비현재 관계가 언젠가 반드시 재활성화된다는 주장.
- 재활성화 시점을 확률적 상수나 고정 인과율로 예측할 수 있다는 주장.
- 미실현 가능성 자체의 인과력.
- 장기 기억/맥락 재활성화 자체의 OASIS 독점적 신규성.

현재 판정:

O2/O3의 장기 구조는 실험적으로 더 강한 지지를 얻었다. 동시에 production 구현의 80-episode/1,200-tick 창은 이 이론적 정의와 불일치하며, 별도의 latent process store가 필요한 구현 갭이 확인됐다.

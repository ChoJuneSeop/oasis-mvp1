# OASIS Causal Research System v0.1 — Summary

Canonical flow:

Past relational structure + current reality
→ possibility composition
→ single realization
→ new relational experience
→ incorporation into past relational structure
→ formation of a new relational structure
→ new possibility composition.

Research priority:
1. Controlled causal intervention.
2. Observe realized flow.
3. Measure first divergence, magnitude, persistence, reconvergence, and long-horizon effect.
4. Use OASIS internal possibility/relation/participant/responsibility structures as explanatory variables only as needed.
5. Do not model unrealized possibilities as persistent parallel future paths.
6. Do not describe realization as rewriting the entire relational structure.

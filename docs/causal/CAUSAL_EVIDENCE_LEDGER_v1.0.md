# OASIS Causal Evidence Ledger v1.0

Date: 2026-09-07
Baseline: OASIS Integrated Core v2.0
Policy: this ledger records the current evidence status. New experiments must append or supersede with an explicit new version; failed or negative results are not overwritten.

## Evidence labels

- OBSERVED: directly observed in current implementation/logs.
- SUPPORTED: survived a relevant control/falsification within the stated scope.
- REFUTED: the tested formulation failed its preregistered or conservative control.
- UNVALIDATED: not directly established yet.
- IMPLEMENTATION: mechanism/code evidence only; not a theory/generalization claim.
- GENERALIZATION-UNVALIDATED: result may hold in the current world/harness only.

## Fixed findings

### 1. Relation/process and sequence history can matter
Status: SUPPORTED within canonical implementation scope.

Removing relation/process information has previously removed or reduced later relational/risk-discovery behavior. Same experience sets with different process histories can yield different downstream relation discovery/participation in prior tests.

Boundary: production `pairKey(a,b)` is order-insensitive. Therefore a claim that production O1 is already fully noncommutative is UNVALIDATED.

### 2. O1 process-order preservation
Status: IMPLEMENTATION / PARTIAL.

Synthetic long-horizon paired tests show that an order-sensitive stored process can remain latent and later diverge, while an order-erased control does not. This establishes feasibility only. The production relation-field does not yet directly prove the full O1 claim.

### 3. O2 non-currentness
Status: OBSERVED / IMPLEMENTATION.

The opt-in latent relation store preserves completed episodes beyond the canonical active windows and records `latentize` and `noncurrent` transitions. Non-currentness is not deletion.

### 4. O3 contextual reactivation
Status: OBSERVED / IMPLEMENTATION, with behavioral support at the set level.

The latent relation store records contextual `reactivate` events using current place/target/gate/risk relation conditions. Shadow comparisons have observed decision-signature differences between the same current state with the latent layer enabled versus disabled.

Boundary: disabling the entire latent set supports JOINT relational contribution. It does not by itself prove that each individual latent episode is causally necessary.

### 5. O4 non-anticipatory constraint
Status: IMPLEMENTATION constraint; behavioral distinctiveness not established.

Future information, pre-scheduled reactivation, and randomness-as-unpredictability are prohibited by the research specification. Earlier O4-violation tests produced future reads without a clear final behavioral difference, so a distinct behavioral O4 effect remains UNVALIDATED.

### 6. Unrealized possibilities have direct causal force
Status: UNVALIDATED.

Stage 30 failed to establish causal consumption of unrealized possibilities. Do not state that an unrealized possibility itself causes later behavior. Stronger evidence currently concerns actually formed relation-processes, actual participation, actual selection, and actual outcomes.

### 7. Longer memory automatically produces more OASIS spiral
Status: REFUTED.

In the long relation-field adapter, extending memory increased activations, participation transitions, choice transitions and structural expansion, but field spirals fell sharply. More memory is not automatically better and is not equivalent to more OASIS structure.

### 8. Danger-rise controls O3 scope or post-reactivation verification
Status: REFUTED for the tested formulations.

Danger-rise timing did not uniquely outperform lag/periodic/surrogate controls. Post-reactivation verification allocation based on danger-rise also failed against matched null timing.

### 9. Current danger level is the OASIS responsibility axis
Status: UNVALIDATED.

Current danger level repeatedly associates with O3 choice-contribution events in 30k and 120k analyses. The association survived strong structural balancing and was positive across a broad balanced-matching multiverse. However, this is observational residual association, not an intervention proving a responsibility operator.

Do not encode `danger == responsibility` as a fixed truth.

### 10. Current danger is only a trivial matching artifact
Status: WEAKENED / NOT SUFFICIENT.

After balancing 650 structural terms, 163 of 164 matchable O3 choice-difference events remained and the residual danger difference stayed positive. Across 257 distinct danger-blind balanced control selections with max |SMD| <= 0.10, all residuals were positive. This weakens the specific-control-selection explanation.

Boundary: only one solution met max |SMD| <= 0.05, and the feasible-design sample is correlated rather than IID. An adversarial worst-case balanced bound remains to be tested.

## Causal research rules now fixed

1. The unit of analysis is a process trace in the current flow, not a fixed coordinate.
2. `stored != currentized != participated != changed decision structure != changed actual choice != changed outcome != rewrote future relation structure`.
3. Immediate behavioral divergence is not required.
4. Difference may emerge, contract, disappear, naturally return, or reappear.
5. Observation-horizon nonoccurrence is right-censored, not permanent failure.
6. Joint relational contribution is a valid finding and must not be falsely decomposed into individual causal claims.
7. Shadow counterfactuals never feed back into the production trajectory.
8. Every new experiment requires a prior-art/necessity kill-search and a frozen scope before execution.
9. Results are graded separately as implementation, causal, and generalization evidence.
10. Canonical experiments and auxiliary mechanism experiments remain structurally separated.

## Next unresolved causal questions

1. Can one completed process identity be traced continuously through formation -> latentization -> contextual reactivation -> participation -> choice/outcome -> later relation rewrite?
2. Which parts of observed joint latent-set contribution are attributable to individual episodes versus irreducible relation sets?
3. Does outcome-linked relation rewrite have a counterfactual effect on later judgments, rather than being only an observed correlation?
4. Does a responsibility state exist independently of current danger, and if so does it act after relation reactivation by changing verification/search/compute depth?
5. Can the current danger residual remain positive under an adversarially selected, fully balanced feasible control assignment?

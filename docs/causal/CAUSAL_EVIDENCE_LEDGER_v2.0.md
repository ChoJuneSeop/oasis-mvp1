## 1. Evidence migration rule

기존 실험결과는 삭제하거나 성공결과로 다시 쓰지 않는다.

v1에서 관측된 사건은 그 당시 실제 측정된 사실로 보존한다. 다만 v2의 이론적 의미로 자동 승격하지 않는다.

특히:
- `relationHistoryBefore/After` 증가 = 구현상 편입 후보신호
- `field-spiral` = 기존 구현의 후속 판단조건 변화 사건
- 둘 모두 v2 H1/H2를 단독으로 입증하지 않는다.

## 2. Inherited internal evidence

기존 OASIS 내부 연구에서 현재까지 유지되는 관측/결과:

- 관계과정과 순서정보가 tested scope에서 판단에 영향을 줄 수 있음: RETAINED INTERNAL EVIDENCE
- 과거 관계가 현재 판단/관계형성에 직접 참여하지 않는 상태와 이후 맥락적 재활성 구현: OBSERVED IMPLEMENTATION
- process identity를 formation → reactivation → participation → outcome까지 추적 가능: OBSERVED IMPLEMENTATION
- same-current target이 같아도 causal process가 동일하다는 뜻은 아님: RETAINED
- 개별 원인의 필요성/충분성과 joint-set attribution은 구분 필요: RETAINED
- full production noncommutativity: UNVALIDATED
- unrealized possibility direct causal force: UNVALIDATED
- danger = responsibility: NOT ASSUMED / UNVALIDATED
- longer memory = better OASIS spiral: previously REFUTED in tested form

## 3. v2 H1 status — Realization and Past-Structure Incorporation

Current status: UNVALIDATED AT STRUCTURAL LEVEL

Available evidence:
- outcomes are observed in current audit harness.
- implementation may show `relationHistory` field growth after outcome.

Interpretation:
- this is an `IMPLEMENTATION_CANDIDATE_INCORPORATION_SIGNAL` only.
- structural incorporation into the existing past relational structure requires additional evidence that the realized experience forms relations with existing past relations or participates in subsequent structure formation.

Required next evidence:
- EX-01.

## 4. v2 H2 status — New Past Relational Structure and Subsequent Reality Relation

Current status: UNVALIDATED AS V2 INTEGRATED HYPOTHESIS

Available inherited evidence:
- some post-outcome judgment-condition changes were previously instrumented through `field-spiral` in narrower runs.
- same-current structural channel differences and overdetermination were observed in earlier causal studies.

Why this is insufficient:
- H2 requires the new past relational structure as a whole to be followed into subsequent reality relations as one continuous process.
- old `future rewrite`, persistence, reconvergence, or downstream-effect labels do not establish this.

Required next evidence:
- EX-02 after EX-01.

## 5. v2 H3 status — Relational Reappearance

Current status: IMPLEMENTATION-OBSERVED / CAUSAL HYPOTHESIS NOT YET FULLY VALIDATED

Available evidence:
- `latentize/noncurrent` and contextual `reactivate` events are present in the canonical harness.
- reactivation can be linked to current-context reasons.

Limits:
- existing implementation evidence alone does not prove general OASIS relational reappearance beyond the current harness.
- reappearance must not be pre-scheduled or future-informed.
- reappearance is not reconvergence.

Required next evidence:
- EX-03 with explicit long-gap/repeated-reappearance tracking.

## 6. v2 H4 status — Relational Persistence-Limit Inquiry

Current status: OPEN_INQUIRY

No claim is currently made that relational persistence has a fixed limit or no limit.

Current implementation storage windows, retention counts, or tick thresholds are not theoretical limits on relational persistence.

A relation not reobserved by horizon is recorded only as:
- `NOT_REOBSERVED_WITHIN_HORIZON`

Required next evidence:
- EX-04 long-horizon study.

## 7. Auxiliary divergence-delay status

Divergence delay is retained only as optional auxiliary time information in paired intervention studies.

It is not a core v2 causal axis and is not interpreted as causal strength.

## 8. Legacy v1 comparator status

The following remain preserved as Legacy/comparator axes:
- divergence delay
- realized change
- persistence
- reconvergence
- accumulated relational effect
- downstream long-horizon effect

They may later be run on the same data for direct comparison with v2 continuous-relational analysis.

## 9. Current v2 evidence priorities

1. EX-01: distinguish structural incorporation from storage growth.
2. EX-02: follow the newly formed whole past relational structure into subsequent reality relations.
3. EX-03: measure natural relational reappearance without scheduled activation.
4. EX-04: investigate persistence limits without declaring extinction from non-observation.
5. Replicate and falsify before causal-rate mathematics.

## 10. Evidence discipline

Do not claim:
- whole-structure overwrite
- persistent unrealized parallel paths
- extinction from horizon non-observation
- structural incorporation from count growth alone
- causal strength from divergence delay
- H2 from one-step post-outcome difference alone

All grades remain scoped to the tested harness unless separately generalized.

## CR-02 — Individual vs joint same-current attribution
Status: RETAINED

Use same-current counterfactual analysis only as an internal causal-mechanism aid. Do not treat shadow branches as realized histories.

## CR-03 — Relation-channel distinction and equifinality
Status: RETAINED

Same current target does not imply same causal process. Different current internal channels also do not by themselves prove long-horizon realized divergence.

## CR-04 — Realized relation incorporation test
Status: NEXT CORE TEST

Question:
When an intervention changes what is actually realized, does the newly realized relational experience enter actual relation history, and can that incorporation be traced without assuming whole-structure rewrite?

Primary observations:
- realized event/action
- relationHistory before outcome
- relationHistory after outcome
- newly incorporated relation experience
- no future leakage

## CR-05 — Paired forward-flow divergence test
Status: PLANNED AFTER CR-04

Start from matched pre-intervention conditions. Change the defined cause/intervention and run each condition forward independently under controlled exogenous flow.

Measure:
1. divergence delay
2. realized-flow change
3. persistence
4. reconvergence
5. accumulated relational difference
6. downstream long-horizon effect

Do not require divergence at t+1.

## CR-06 — Accumulated relational effect
Status: PLANNED

Question:
Does a difference in realized relation incorporation alter later relation-structure formation and later realized flow?

Internal possibility composition, reactivation, participation, and responsibility traces are explanatory variables, not replacements for realized-flow observation.

## CR-07 — Long-horizon reconvergence and reappearance
Status: PLANNED

Allow all outcomes:
- no divergence
- delayed divergence
- divergence then natural return
- divergence, return, and later reappearance
- persistent divergence

Horizon non-divergence is right-censored, not permanent equivalence.

## CR-08 — Production order distinction
Status: SEPARATE

Test production order effects without assuming that synthetic noncommutativity already proves production noncommutativity.

## CR-09 — Responsibility-axis identification
Status: AFTER CORE CAUSAL CHAIN

Do not use `danger = responsibility` as a shortcut. Responsibility must be independently identified and tested.

## CR-10 — Generalization
Status: LAST

External-model, industrial, or real-world superiority claims require separate validation outside the current harness.

## v1.0 experiment rule

The canonical research order is:

`intervention design -> observed realized flow -> realized relation incorporation -> long-horizon difference measurement -> internal OASIS explanation -> replication -> causal-rate formalization`

Complete internal possibility-space mathematics is not a prerequisite for the first causal experiments.

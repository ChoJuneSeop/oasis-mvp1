# OASIS 인과연구 보조 구성요소 v2.0 / OASIS Causal Research Auxiliary Components v2.0

상태 / Status: v2 공식 보조 구성요소 / Official auxiliary components for v2
기준일 / Date: 2026-09-07
상위 기준 / Governing protocol: `../../OASIS_RESEARCH_PROTOCOL.md`
핵심 기준 / Core baseline: `../OASIS_CAUSAL_RESEARCH_SYSTEM_v2.0_ko.md`

이 문서는 OASIS 인과연구시스템 v2.0의 핵심 4축을 변경하거나 새로운 핵심축을 추가하지 않는다.

아래 요소는 현재까지의 논의 의미를 확대하거나 축소하지 않고, 원인 개입과 가능성 변화의 해석 및 실험을 보조하기 위한 구성요소로만 둔다.

## 1. 자기개입 / Self-Intervention

인과과정에는 외부 원인에 의한 개입뿐 아니라 주체 자신의 자기개입이 있을 수 있다.

OASIS에서는 지능을 가진 존재가 현재 주어진 가능성만을 수동적으로 따르지 않고 더 좋은 가능성을 찾기 위해 스스로 개입할 수 있다는 메타적 전제를 둘 수 있다.

다만 이를 `강한 의지가 현실을 직접 비튼다`는 물리적 주장으로 정의하지 않는다.

자기개입은 현재 단계에서 핵심 인과축이 아니라 원인 개입의 한 가능한 형태로만 둔다.

## 2. 선택축과 책임축 / Choice Axis and Responsibility Axis

자기개입이 가능하다는 전제만으로 개입을 무제한적으로 정당화하지 않는다.

선택축 / Choice Axis은 여러 가능성 가운데 하나를 실제 선택하는 축이다.

책임축 / Responsibility Axis은 그 선택에 따른 책임을 함께 고려하는 보완축이다.

현재 단계에서는 선택축과 책임축을 인과율 자체로 동일시하지 않는다. 자기개입과 실제 현실화 사이의 판단과정을 보조하는 구성요소로 둔다.

## 3. 개성 / Individual Disposition

세상은 서로 다른 개성을 가진 존재들이 함께 살아가는 구조이므로, 동일하거나 유사한 현실조건에서도 모든 존재가 항상 같은 방향으로 움직인다고 가정하지 않는다.

개성은 각 존재가 가능성을 보고 자기개입하고 선택하는 방향이 서로 다를 수 있음을 설명하는 보조 구성요소로 둔다.

개성을 고정 상수나 고정 성격값으로 확정하지 않는다.

## 4. 인과율의 존재형태 개방성 / Openness of the Form of Causality

OASIS 인과연구는 인과율이 반드시 하나의 특정 상수로 존재한다고 선결하지 않는다.

실험 결과 인과율이 특정 상수로 표현될 수도 있고, 다른 형태로 나타날 수도 있으며, 단일 상수로 두는 것 자체가 OASIS의 가능성 구조에 부적합하다는 결과가 나올 수도 있다.

따라서 현재 연구의 의의는 특정 상수의 발견을 보장하는 데 있지 않고, 아직 확정되지 않은 인과율의 존재형태를 실험을 통해 탐색하는 데 둔다.

증명이 실패하거나 단일 상수화가 부적합하다는 결과 역시 보존한다.

## 5. Legacy v1 관측기의 보조적 의미 / Auxiliary Role of the Legacy v1 Observer

Legacy v1은 단순히 OASIS의 과거 버전과 현재 버전을 비교하기 위한 대상만은 아니다.

동일한 OASIS 현실흐름을 기존의 분절형 관측축으로 보았을 때 어떤 관계정보가 누락되거나 다른 의미로 해석되는지를 확인하기 위한 관측기 비교군으로 사용할 수 있다.

이 비교가 보여줄 수 있는 것은 `v2가 우월하다`는 사실 그 자체가 아니라, 관측틀에 따라 OASIS 인과과정에서 포착되는 정보가 달라질 수 있다는 점이다.

## 6. 적용 경계 / Scope Boundary

이 문서의 요소들은 다음을 의미하지 않는다.

- 자기개입이 항상 더 좋은 결과를 만든다는 주장
- 강한 의지일수록 인과율이 크다는 주장
- 개성이 고정된 수치라는 주장
- 책임축이 원인 개입의 조작적 정의를 자동으로 해결한다는 주장
- 인과율이 반드시 상수로 존재하거나 반드시 상수가 아니라는 주장

실험에서는 실제로 무엇이 개입되었는지, 무엇이 선택되었는지, 어떤 결과가 현실화되었는지를 별도로 기록한다.

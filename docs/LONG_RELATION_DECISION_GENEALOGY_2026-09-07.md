# OASIS 장기 관계 선택 계보 추적 — 2026-09-07

## 지위

- 기존 canonical 실험을 수정하거나 대체하지 않는다.
- production `relation-field.js`는 수정하지 않았다.
- compatibility guard에서 기존 `18/80/1200`, browser-world 4,000틱, open-possibility 520틱 조건을 다시 확인했다.
- 본 실험은 A 확장조건 `18/80/12000`에서 장기 관계가 실제 선택 직전에 직접 기여하는지 추적하는 계보 검증이다.
- Stage 30의 미실현 가능성 인과효과와 무관하다. 본 실험에서 사용된 관계는 모두 실제로 형성된 relation event / episode이다.

## 이전 실험에서 수정해야 했던 위험

이전 완전요인 실험의 tick 3,304 선택차이는 `tickW` 완료 뒤 같은 상태를 재평가한 값이어서, `choose()` 뒤 갱신된 `P.target`이 관계 활성 조건에 다시 들어가는 순환효과 가능성이 있었다.

따라서 이번 검증에서는 `choose()` 호출 직전의 동일 상태를 고정하고 다음 두 계산을 수행했다.

1. 확장조건: episode age cutoff = 12,000
2. 반사실 조건: episode age cutoff = 1,200

그 뒤 실제 확장조건의 `choose()`를 그대로 실행했다.

- `루카↔엘리`
- `루카↔아론`
- `아론↔엘리`
- `???↔아론`
- `???↔루카`
- `???↔엘리`

중요: 각각을 하나씩 제거했을 때는 선택이 계속 `road`였다.

그러나 오래된 exclusive 관계집합 전체를 제거하면 선택이 `lake`로 바뀌었다.

따라서 이 사례의 직접기여는 단일 과거 기억 하나의 효과가 아니라 **여러 과거 관계가 현재에서 함께 구성한 관계장 수준의 결합효과**이다.

1. tick 3,304의 장기 관계 선택차이는 실제 선택 직전에도 존재한다.
2. 1,200틱을 넘긴 실제 형성 관계가 현재 선택 계산에 다시 참여할 수 있다(A 확장조건).
3. 이 효과는 후보 생성이나 leader 변경이 아니라 선택순위/참여 구조의 재배열로도 나타날 수 있다.
4. 효과는 단일 episode 하나가 아니라 여러 오래된 관계의 결합으로 발생했다.
5. `???↔루카`는 decision checkpoint 기준 1,650틱의 비현재 구간 뒤 다시 현재화된 명확한 사례다.
6. 선택 결과는 새로운 관계 episode를 생성하여 다음 관계구조를 다시 썼다.

### 확인되지 않음

1. 이 첫 사례에서는 outcome 직후 판단서명이 바뀌지 않았으므로 나선이 발생하지 않았다.
2. tick 3,595에서 생성된 2세대 episode가 훗날 언제 다시 현재화되는지는 아직 미추적이다.
3. canonical 1,200틱 production 설정 자체가 >1,200틱 재활성화를 지원한다는 뜻은 아니다.
4. 여러 독립 세계에서 같은 계보 패턴이 일반화되는지는 미확인이다.
5. O1 순서비가환성이 이 계보의 원인이라는 증거는 아니다.
6. 미실현 가능성의 인과력(Stage 30)은 여전히 미검증이다.

## OASIS 관점 해석

이번 첫 계보는 다음을 보여준다.

`과거 관계과정`
-> `현재가 아닌 기간`
-> `새 현재에서 관계적 재활성화`
-> `현재 판단구조에 결합 기여`
-> `하나의 실제 선택`
-> `결과`
-> `새 관계과정 생성`

그러나 마지막 단계에서 곧바로:

`결과 -> 다음 판단서명 변화`

가 발생하지는 않았다.

따라서 OASIS에서는 관계의 효과를 `다음 틱에서 즉시 차이가 났는가`로만 판단하면 안 된다. 이번 결과로 새로 생성된 tick 3,595 episode도 다시 잠재될 수 있고, 훨씬 뒤의 현재에서 의미를 얻을 수도 있으며, 관찰기간 내 다시 나타나지 않을 수도 있다.

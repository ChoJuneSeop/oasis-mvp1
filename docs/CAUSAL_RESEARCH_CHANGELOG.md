- Fixed `인연필드 / Relational Field` as **열린 가능성 조합의 장 / Open Field of Possibility Combinations**, without asserting mathematical infinity, a physical field, or persistent parallel realities.

- Preserved negative H2 evidence that relational reappearance alone did not cause behavioral divergence in tested horizons and that finer within-key footprint testing is blocked by the current compressed representation.
- Completed EX-04P disposition sequence A/B/C/D/DL. Conditional matched effects were observed, but disposition remained unnecessary and insufficient.
- Completed EX-04M multi-OASIS study: same-prior/different-Past-Relational-Structure contrasts diverged in **3/3** canonical pairs; different-prior/same-PRS matched-prestate effects occurred in **2/3** canonical pairs.

- Repeatedly observed that branches can return to the same current output while retaining different Past Relational Structures: same current output does not identify one causal process.
- Completed EX-06 Legacy v1 observer comparison. Legacy axes remain useful for divergence/reconvergence/accumulated-effect measurement; v3 explicitly retains condition identity, matched-prestate lineage and same-output/different-PRS process state. Universal v3 superiority was not established.

## v2.0 — 2026-09-07

- Promoted the continuous-relational causal framework to the official OASIS Causal Research System v2.0.
- Preserved `OASIS_RESEARCH_PROTOCOL.md` as the governing protocol above all causal documents.
- Fixed the canonical continuous process as: past relational structure + current reality → possibility composition → single realization → realized experience → incorporation into the existing past relational structure → formation of a new past relational structure → relation between the entire new past relational structure and subsequent reality → new relational structure / possibility composition.
- Unified theoretical terminology on `과거 관계구조 / Past Relational Structure`; `관계이력 / relation history` is no longer a core theoretical term. Existing implementation field names such as `relationHistory` remain compatibility-only.
- Replaced the v1 core measurement-axis block with four v2 research axes:
  1. realization and incorporation into past relational structure
  2. formation of new past relational structure and subsequent reality relation
  3. relational reappearance possibility
  4. inquiry into limits of relational persistence
- Integrated the former separate past-structure-change and renewed-relation hypotheses into one continuous H2.
- Reclassified divergence delay as auxiliary timing information only, not causal strength.
- Reclassified v1 realized change, persistence, reconvergence, accumulated relational effect, and downstream long-horizon effect as Legacy/comparator concepts.
- Corrected structural-incorporation evidence: simple `relationHistoryBefore/After` growth is only an implementation candidate signal and is insufficient to validate incorporation into the past relational structure.
- Defined relational reappearance as a past relation that was not directly participating in current judgment/relational formation and later becomes related to the current reality again without pre-scheduled future information.
- Rejected extinction claims from horizon non-observation. The correct status is `NOT_REOBSERVED_WITHIN_HORIZON`.
- Fixed H4 as an open inquiry into whether relational persistence has observable limits; proof of an absolute never-relates-again state is not required.
- Added v2 experiment sequence EX-00 through EX-07, beginning with internal OASIS prior-work review and ending with causal-rate mathematical formalization only after structural, long-horizon, replication, and comparator validation.
- Added `tools/causal-trace-ledger-v2.mjs` and switched the active causal validation workflow to v2.
- Preserved v1 documents, trace implementation, evidence, and experiment index unchanged as Legacy/comparator material for future head-to-head analysis.
- Added `CAUSAL_AUXILIARY_COMPONENTS_v2.0.md` without changing the four v2 core axes. The auxiliary components are self-intervention, choice/responsibility axes, individuality, openness of the causal-rate form, and the Legacy v1 observer-comparison role.
- Applied those auxiliary components to the experiment index as optional observations only; they do not by themselves establish causal strength or validate H1-H4.

## v1.0 — 2026-09-07

- Promoted the v0.1 observational baseline to the official OASIS Causal Research System v1.0.
- Fixed the canonical process as: past relational structure + current reality → possibility composition → single realization → new realized relational experience → incorporation into past relational structure → formation of a new relational structure → new possibility composition.
- Rejected whole-structure rewrite/overwrite semantics after realization.
- Fixed that only realized possibilities enter actual relational history; unrealized possibilities are not persistent parallel paths.
- Reframed causal tracing from `future relation rewrite` to realized-relation incorporation, accumulation, and subsequent relational-structure formation.
- Defined the primary long-horizon measurement axes: divergence delay, realized change, persistence, reconvergence, accumulated relational effect, and downstream long-horizon effect.
- Kept internal possibility structures separate from externally observed realized flow.
- v1.0 remains preserved as a Legacy/comparator system after v2.0 rather than being rewritten or deleted.

- Defined realized possibilities as new relational experiences incorporated into accumulated past relational structure.
- Rejected whole-structure overwrite wording.
- Rejected persistent parallel-path interpretation of unrealized possibilities.
- Prioritized long-horizon divergence, persistence, reconvergence, and downstream effects.

# OASIS 인과연구시스템 v0.1

상태: 연구 기준본
기준일: 2026-09-07

## 1. 기본 관계 과정

OASIS 인과연구는 다음 흐름을 기준으로 한다.

과거 관계구조 + 현재 현실
→ 가능성 조합
→ 단일 현실화
→ 새 관계 경험 생성
→ 과거 관계구조에 편입
→ 새로운 관계구조 형성
→ 새로운 가능성 조합

현실화된 가능성은 실제 경험이 되어 축적된 과거 관계구조의 일부로 편입된다. 현실화 이후 관계구조 전체가 덮어써지거나 전면 재작성된다고 보지 않는다.

미실현 가능성은 독립된 미래 경로나 평행한 현실로 보존되지 않는다. 그것은 해당 현재에서 존재했지만 현실화되지 않은 가능성 조합이다.

## 2. 인과 연구의 핵심 대상

인과를 단순히 “원인 A가 결과 B를 만들었다”는 단일 결과 연결로 축소하지 않는다.

연구 대상은 원인 개입이 장기적으로 다음 연쇄를 어떻게 바꾸는가이다.

가능성 조합
→ 단일 현실화
→ 현실화된 관계 경험의 편입
→ 이후 관계구조 형성
→ 이후 새로운 가능성 조합

## 3. 1차 실증 층

1차 증거는 실관측 가능한 현실화 흐름에서 얻는다.

각 개입 조건에서 다음을 기록·비교한다.
- 실제로 현실화된 사건과 행동
- 실제로 현실화된 관계 경험
- 최초 분기 시점
- 분기 변화량
- 차이의 지속시간
- 재수렴 여부
- 장기 후속 영향

즉시 다음 단계에서 차이가 보이지 않는다는 이유만으로 인과효과가 없다고 판정하지 않는다.

## 4. 내부 설명 층

관측된 인과 차이를 설명하기 위해 필요할 때 다음 OASIS 내부 구조를 분석한다.
- 가능성 조합
- 관계 재활성
- 참여상태
- 책임축
- 구조적 확장

내부 가능성 구조와 외부 실관측 현실화 결과를 혼동하지 않는다.

미실현 가능성은 지속되는 미실현 경로로 취급하지 않는다. 특정 현재에서 형성되었으나 그 시점에 현실화되지 않은 가능성 조합으로 다룬다.

## 5. 연구 순서

1. 통제 가능한 원인 개입을 설계한다.
2. 각 조건에서 현실화된 흐름을 관측한다.
3. 장기 분기와 지속성을 측정한다.
4. 관측된 차이를 설명하는 데 필요한 내부 OASIS 구조만 분석한다.
5. 대응 조건, 반복 시드, 통제된 반사실 시뮬레이션으로 반복 검증한다.
6. 관측 지표가 안정된 이후 인과 계량식을 도입한다.

전체 인연필드 거리나 내부 구조의 완전한 수학화는 1차 인과실험의 선행조건으로 두지 않는다.

## 6. v0.1 연구 원칙

OASIS의 1차 인과율은 미래 가능성 트리를 전부 열거하는 방식보다, 원인 개입이 현실화된 관계의 누적과 이후 관계구조 형성을 시간에 따라 어떻게 변화시키는지를 실관측에 기반해 계량하는 방향으로 설계한다.

이 문서는 현실화 때마다 관계구조 전체가 재작성된다고 설명하거나, 미실현 가능성을 지속되는 평행 미래 경로처럼 설명한 기존 표현보다 우선한다.

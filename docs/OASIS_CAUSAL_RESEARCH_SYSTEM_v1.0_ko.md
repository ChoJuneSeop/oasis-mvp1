# OASIS 인과연구시스템 v1.0

상태: 공식 연구 기준본
기준일: 2026-09-07
선행 기준: OASIS 인과연구시스템 v0.1

## 1. 기본 관계 과정

OASIS 인과연구는 다음 흐름을 기준으로 한다.

과거 관계구조 + 현재 현실
→ 가능성 조합
→ 단일 현실화
→ 새 관계 경험 생성
→ 과거 관계구조에 편입
→ 새로운 관계구조 형성
→ 새로운 가능성 조합

핵심 원칙은 누적적 편입이다. 현실화된 가능성은 실제 경험이 되어 이후의 과거 관계구조 일부가 된다. 관계구조 전체를 매 현실화마다 덮어쓰거나 전면 재작성한다고 보지 않는다.

미실현 가능성은 독립된 미래 경로나 평행 현실로 지속되지 않는다. 그것은 해당 현재에서 형성되었으나 현실화되지 않은 가능성 조합이다. 실제 관계이력에 편입되는 것은 현실화된 가능성뿐이다.

## 2. 인과 연구의 핵심 질문

OASIS에서 인과는 단순한 `원인 A → 결과 B`의 연결만을 뜻하지 않는다.

핵심 질문은 다음과 같다.

> 원인 개입이 어떤 가능성을 현실화시키고, 그 현실화된 관계 경험이 과거 관계구조에 편입된 뒤 이후의 관계구조와 현실 형성에 어떤 차이를 만드는가?

따라서 연구 대상은 다음 연쇄의 장기 변화이다.

가능성 구성
→ 단일 현실화
→ 현실화된 관계 경험 생성
→ 과거 관계구조에 누적·편입
→ 새로운 관계구조 형성
→ 다음 가능성 구성

## 3. 외부 실관측 층

1차 증거는 실제로 현실화된 흐름에서 얻는다.

각 개입 조건에서 다음을 기록·비교한다.
- 실제 현실화된 사건과 행동
- 실제 현실화된 관계 경험
- 최초 분기 시점
- 분기 변화량
- 차이의 지속시간
- 재수렴 여부
- 장기 후속 영향

한 단계 뒤에서 차이가 없다는 이유만으로 인과효과가 없다고 판정하지 않는다. 효과의 출현 시점은 사전에 고정하지 않으며 장기 관측을 허용한다.

## 4. 내부 설명 층

외부에서 관측된 차이를 설명하기 위해 필요할 때 다음 내부 구조를 분석한다.
- 가능성 조합
- 관계과정 및 관계 재활성
- 참여상태
- 책임축
- 구조적 확장

내부 가능성 구조는 외부 실관측값과 구분한다. 미실현 가능성을 지속되는 '미실현 경로'로 취급하지 않는다.

## 5. 개입과 비교 원칙

가능하면 동일하거나 대응 가능한 초기조건에서 원인 변수 하나를 통제해 바꾼다.

각 조건은 독립적으로 앞으로 전개한다. 연구는 미래 결과에서 과거 원인을 단순 역산하는 방식이 아니라, 원인 개입 이후 현실화와 관계 누적의 차이를 전진 추적하는 방식이다.

시뮬레이션의 shadow/counterfactual 조건은 분석용이며 실제 생산 현실의 상태로 되먹임하지 않는다.

## 6. v1.0 핵심 측정축

1차 인과효과는 단일 스칼라로 즉시 축약하지 않는다. 최소한 다음 축을 별도로 기록한다.

1. 분기 지연: 원인 개입 후 최초 관측 차이가 나타날 때까지의 시간
2. 현실화 변화: 실제 사건·행동·관계 경험의 차이
3. 지속성: 발생한 차이가 유지되는 기간
4. 재수렴: 서로 다른 흐름이 이후 다시 유사한 현실로 수렴하는지 여부
5. 누적 관계효과: 새로 현실화된 관계 경험의 편입이 이후 관계구조 형성에 미친 차이
6. 장기 후속효과: 더 먼 시점의 현실화 흐름에 남는 영향

필요한 경우 이 축들을 이용해 후속 버전에서 인과율 계량식을 정의한다.

## 7. 연구 순서

1. 원인 개입과 통제조건을 정의한다.
2. 각 조건의 실제 현실화 흐름을 기록한다.
3. 현실화된 새 관계 경험이 과거 관계구조에 편입되는 사건을 기록한다.
4. 이후 형성되는 관계구조와 현실화 흐름의 장기 차이를 측정한다.
5. 차이가 확인된 구간에서 필요한 내부 OASIS 구조를 분석한다.
6. 반복 시드, 대응 조건, 독립 실험으로 재현성을 검증한다.
7. 관측축이 안정된 뒤 인과율 계량식을 도입한다.

전체 인연필드 거리나 내부 구조의 완전한 수학화는 1차 실증의 선행조건으로 두지 않는다.

## 8. 용어 규칙

사용:
- 관계 경험의 편입
- 관계이력의 누적
- 새로운 관계구조 형성
- 현실화 이후 다음 판단조건 변화

사용하지 않음:
- 현실화 때마다 관계구조 전체 재작성
- 현실화 때마다 전체 필드 덮어쓰기
- 미실현 가능성의 지속적 평행 경로
- 미실현 경로를 직접 관측했다는 표현

## 9. v0.1에서 v1.0으로의 승격

v0.1의 실관측 우선 원칙을 유지하면서 다음을 명확히 고정했다.
- 현실화된 가능성만 실제 관계이력에 편입된다.
- 편입은 전체 관계구조 재작성과 구분한다.
- 인과 연구의 중심은 현실화된 관계 경험의 누적과 이후 관계구조 형성이다.
- `rewrite` 중심의 연구 용어를 `incorporation / accumulation / subsequent formation` 중심으로 교정한다.
- 장기 인과효과를 분기 지연, 현실화 변화, 지속성, 재수렴, 누적 관계효과, 장기 후속효과로 분해한다.

이 문서는 OASIS 인과연구의 현재 최우선 기준본이다.

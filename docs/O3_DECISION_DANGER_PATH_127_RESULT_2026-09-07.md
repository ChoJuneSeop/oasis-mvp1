# O3 Decision-Danger Path 127 Control — 2026-09-07

## Scope
Auxiliary implementation/deconfounding evidence only. This test does not modify the canonical production trajectory and does not establish an independent responsibility operator.

## Question
The prior O3 signal-discovery runs found that current `S.danger` discriminated completed-process O3 choice-difference events (30k AUC 0.6500821; 120k AUC 0.6536399). A 3-phase path-deconfounding pilot showed that shifting the danger-sensitive O3 retrieval path had no effect, while shifting the danger-sensitive participant/ranking path changed the observed association.

This test asks a narrower question:

> Is the observed danger/O3 association exceptional relative to many distribution-preserving phase randomizations of only the `danger -> participant/ranking` path, while O3 retrieval and the actual production world remain canonical?

## Design
- Production world trajectory: canonical and unchanged.
- Completed-process O3 retrieval: canonical and identical for all conditions.
- Only same-current shadow participant/ranking evaluations receive a phase-shifted danger value.
- 127 unique per-party circular phase shifts of the canonical danger-at-decision tape.
- Actual current danger remains the measured signal for AUC; shifted danger is used only inside the shadow decision/ranking path.
- Future values can appear only in offline shadow controls; production choice never reads them.
- Circular shifts preserve the empirical danger-flow distribution and much of its serial structure, but the resulting empirical p-value is treated only as a path-randomization stress-test measure because nonstationarity may remain.

## Interpretation
1. The canonical danger AUC 0.6501 is **not exceptional** relative to the distribution generated by randomizing only the current alignment of the danger-to-participant/ranking path.
2. Therefore the simple confound hypothesis — "the AUC exists only because the same current danger value is directly reused by the participant/ranking formula" — is not sufficient.
3. This does **not** establish danger as causal, nor does it establish a responsibility axis. The residual association can arise because danger co-varies with a broader trajectory/state/history structure sampled at decision times.
4. In OASIS terms, current danger should currently be treated as a **flow-context marker / responsibility-candidate signal**, not an independent responsibility operator.
5. A key remaining confound is event-time/state sampling: `S.danger` itself is driven by the exogenous `env(t)` flow, but the moments at which decisions occur depend on the agent's evolving trajectory, targets, relations, visits, and movement. O3 choice-difference events may therefore be concentrated in particular structural states and decision times that also happen to have higher danger.

## Next falsification target
Separate current danger from the broader co-evolving structural state. Before execution, kill-search conditional randomization / matched-state / blockwise time-series methods. Candidate observable state variables include current place, target and target risk, discovered/visited structure, relation-field size/active state, latent-process count, recent relation structure, and decision-time/trajectory phase. Avoid arbitrary fixed bins where possible.

## Evidence grade
Mechanism/deconfounding evidence. No superiority claim. No independent responsibility-axis implementation claim.

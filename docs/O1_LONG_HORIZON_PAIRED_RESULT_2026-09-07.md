# O1 장기 순서이력 쌍대 검증 결과 — 보조 합성실험

## 실험 지위
이 문서는 기존 OASIS 브라우저/관계장 검증의 결과를 대체하지 않는다.

- 분류: 보조 합성실험(auxiliary synthetic feasibility test)
- 용도: O1 과정순서 보존 연산자의 장기 발현 가능성 검토
- 논문 본증거 여부: 아니오
- 기존 relation-field.js 구현 증명 여부: 아니오
- 기존 NoRelation/NoFeedback/open-possibility 결과 수정 여부: 없음

현재 production `relation-field.js`는 관계 키를 `pairKey(a,b)`에서 정렬하므로 관계 키 수준에서는 A→B와 B→A를 구분하지 않는다. 반면 episode의 `a`, `b`, `from=[prev.t,cur.t]`에는 순서 흔적이 남는다. 따라서 기존 본체를 완전한 비가환 관계연산 구현으로 해석하지 않는다.

또한 기존 relation-field 실험은 최근 relation 18개, episode 80개, 1200-tick 활성 연령 제한을 가진다. 아래 1,000,000단계 합성실험은 이 기존 유한 창을 확장한 별도 조건이며, 두 실험의 수치를 직접 비교하지 않는다.

## 목적
동일한 사건 A와 B를 A→B / B→A로만 다르게 보존하고, 이후 1,000,000 단계의 외생 현실을 완전히 동일하게 흘렸을 때 순서차이가 언제 처음 현재화될 수 있는지 측정한다. 즉시 행동차이는 성공조건이 아니다.

## 조건
- 시드: 17, 43, 101
- 각 시드: 1,000개의 쌍
- 과정 생성: 최초 100,000 단계 동안 100단계 간격
- 전체 관찰: 1,000,000 단계
- 외부 현실: seed + tick으로만 생성되어 두 순서 경로에 동일
- 미래 재활성화 시점 예약 없음
- 순서제거 대조군: A/B 순서를 정규화하여 동일 서명으로 저장
- production relation-field.js 직접 사용: 하지 않음

- 10,000 단계: 시드별 최초 차이 발현 1 / 0 / 1 쌍

- 1,000,000 단계: 512 / 505 / 483 쌍

## 허용되는 판정
1. 순서차이를 즉시 다음 행동에서만 찾는 설계는 O1 장기 가설을 충분히 시험하지 못한다.
2. 순서를 서로 다른 과정서명으로 보존하는 합성 연산구조에서는 동일한 이후 외생 흐름에서도 발현 시점이 장기적으로 달라질 수 있다.
3. 관찰 종료까지 미발현인 경우를 허용할 수 있다.
4. 순서제거 대조군에서 차이가 사라지므로 이 합성 장치 내부에서는 순서서명 보존 여부가 분리 원인이다.

## 금지되는 판정
- 기존 OASIS relation-field가 이미 비가환 연산을 완전히 구현했다.
- A→B와 B→A의 차이가 실제 OASIS에서 반드시 미래 현실을 바꾼다.
- 위 숫자가 기존 4000-tick browser-world 또는 520-tick open-possibility 실험을 반박하거나 대체한다.
- 장기 발현률이 OASIS의 성능 또는 우월성을 의미한다.
- 미발현 과정이 언젠가는 반드시 활성화될 것이라고 추정한다.

## 다음 본검증 조건
논문 본증거로 승격하려면 production relation-field를 직접 덮어쓰지 않고 별도 장기 어댑터를 만들어야 한다. 어댑터는 기존 관계 형성·참여·선택·결과반영 논리를 그대로 유지하되, `18/80/1200` 유한 창만 실험변수로 명시적으로 분리한다. 그 뒤 다음 두 조건을 병렬로 실행한다.

1. 기존조건 재현: 18 / 80 / 1200 유지
2. 장기확장조건: 동일 관계규칙을 유지하고 시간/보존 창만 확장

두 조건의 결과가 다른 경우 어느 쪽이 맞다고 판정하지 않고, 왜 유한 창이 장기 관계과정의 발현을 제한하거나 변화시키는지를 OASIS 흐름 관점에서 분석한다.

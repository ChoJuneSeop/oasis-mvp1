# O1 장기 순서이력 쌍대 검증 결과

## 목적
동일한 사건 A와 B를 A→B / B→A로만 다르게 보존하고, 이후 1,000,000 단계의 외생 현실을 완전히 동일하게 흘렸을 때 순서차이가 언제 처음 현재화되는지 측정한다. 즉시 행동차이는 성공조건이 아니다.

## 조건
- 시드: 17, 43, 101
- 각 시드: 1,000개의 쌍
- 과정 생성: 최초 100,000 단계 동안 100단계 간격
- 전체 관찰: 1,000,000 단계
- 외부 현실: seed + tick으로만 생성되어 두 순서 경로에 동일
- 미래 재활성화 시점 예약 없음
- 순서제거 대조군: A/B 순서를 정규화하여 동일 서명으로 저장

## 결과
### 시드 17
- 최초 차이 발현 쌍: 512 / 1000
- 미발현: 488 / 1000
- 최초 차이 중앙값: 380,063.5 단계
- 90백분위: 807,615 단계
- A→B만 현재화: 225
- B→A만 현재화: 197
- 둘 다 서로 다른 시점에 현재화: 90
- 순서제거 대조군 차이 발현: 0

### 시드 43
- 최초 차이 발현 쌍: 505 / 1000
- 미발현: 495 / 1000
- 최초 차이 중앙값: 409,110 단계
- 90백분위: 839,477 단계
- A→B만 현재화: 204
- B→A만 현재화: 216
- 둘 다 서로 다른 시점에 현재화: 85
- 순서제거 대조군 차이 발현: 0

### 시드 101
- 최초 차이 발현 쌍: 483 / 1000
- 미발현: 517 / 1000
- 최초 차이 중앙값: 388,420 단계
- 90백분위: 803,988 단계
- A→B만 현재화: 200
- B→A만 현재화: 192
- 둘 다 서로 다른 시점에 현재화: 91
- 순서제거 대조군 차이 발현: 0

## 시간창 비교
- 10,000 단계: 시드별 최초 차이 발현 1 / 0 / 1 쌍
- 100,000 단계: 42 / 35 / 31 쌍
- 1,000,000 단계: 512 / 505 / 483 쌍

## 판정
1. 순서차이의 효과를 바로 다음 현실에서 찾는 설계는 부적절하다.
2. 동일한 이후 현실에서도 서로 다른 과정순서가 장기간 잠재된 뒤 다른 시점에 현재화되는 구조를 구현 수준에서 확인했다.
3. 관찰 종료까지 차이가 나타나지 않는 경우도 약 절반 존재하며, 이를 실패로 간주하지 않는다.
4. 순서제거 대조군에서는 최초 차이 발현이 0이므로 실험 장치 자체의 임의 분기가 아니라 순서서명 보존 여부에 의해 분리가 발생했다.

## 한계
이 결과는 O1 연산자의 장기 메커니즘이 계산적으로 가능함을 보이는 합성 검증이다. 실제 OASIS 관계장 전체에서 순서차이가 자연스럽게 어떤 관계를 만들고, 참여·가능성·선택·후속 현실을 변화시키는지까지 입증한 것은 아니다. 특히 현재 재활성화 조건은 순서서명에서 유도된 합성 관계키이므로, 논문 본증거로 승격하기 전에 실제 relation-field 구조를 사용한 재검증이 필요하다.

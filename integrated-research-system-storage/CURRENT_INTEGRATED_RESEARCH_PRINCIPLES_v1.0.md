# OASIS Current Integrated Research Principles v1.0

Date: 2026-09-08
Status: Imported canonical principles snapshot
Source priority: `OASIS_RESEARCH_PROTOCOL.md` → current domain baselines → experiment-specific documents → Legacy/comparator evidence

## 1. Internal prior-work first

Every new OASIS research task begins by checking OASIS internal prior work.

Sequence:

`internal prior work`
→ `current fixed structure`
→ `unresolved question`
→ `external prior research only if necessary`
→ `direct validation`
→ `result incorporation`

Do not restart already tested, falsified, retired, or fixed questions without a clear reason such as replication, generalization, a stronger counterexample, removal of a known limitation, or a stronger baseline.

## 2. Kill-search before experiments

Kill-search is required before a new experiment.

Its role is limited to:
- finding essentially identical prior structures;
- attacking novelty and inventive step;
- finding counterexamples;
- checking whether a simpler existing explanation collapses the OASIS claim;
- borrowing validation methods when appropriate;
- checking exaggeration, duplication, and omission before paper/patent use.

Kill-search must not force OASIS into an external theoretical framework.

## 3. No reverse import of external frameworks

External theories do not define OASIS merely because they are standard, popular, or terminologically similar.

Preserve OASIS-native structures unless evidence requires change:
- continuous reality flow;
- relational process;
- participation state;
- possibility composition;
- choice/responsibility interaction;
- single realization;
- incorporation of realized experience into past relational structure;
- renewed relation between past relational structure and subsequent reality;
- possible reappearance/re-currentization of relations.

## 4. Flow Preservation Principle

English: **Flow Preservation Principle**
Korean explanation: OASIS를 독립 모듈로 해체해서 검증하지 않고, 하나의 현실 흐름을 유지한 상태에서 필요한 관계·결합·정보경로만 국소적으로 개입하는 원칙.

Canonical validation target:

`Past Relational Structure + Current Reality`
→ `relation re-currentization / participation`
→ `possibility composition`
→ `choice / responsibility / reality constraints`
→ `single realization`
→ `realized experience`
→ `incorporation into existing past relational structure`
→ `new past relational structure`
→ `relation with subsequent reality`
→ `new relational and possibility structure`

The arrows do not mean the internals are strictly one-way or linear.

## 5. Official validation sequence

1. `F0 Full Flow Baseline`
   - Korean: 전체 흐름 기준선 관측.
2. `F1 Flow-Preserving Local Intervention`
   - Korean: 전체 흐름을 유지한 국소개입.
3. `F2 Interaction / Coupling Perturbation`
   - Korean: 독립요소가 아니라 결합관계를 건드리는 검증.
4. `F3 Longitudinal Emergent Validation`
   - Korean: 장기 흐름에서 발생하는 재현재화·비현재화·구조확장·자연복귀 등을 관찰.
5. `F4 External / Domain Validation`
   - Korean: 다른 환경·도메인에서 동일 OASIS 구조가 어떻게 작동하는지 검증.
6. `F5 Causal Synthesis`
   - Korean: 앞 단계 증거를 과장 없이 종합.

## 6. Decomposition-induced failure

English: **Decomposition-Induced Failure**
Korean explanation: 검증을 위해 OASIS를 분해하는 과정에서 검증대상 현상의 성립조건 자체가 사라져 발생한 실패.

Such failure is not automatically OASIS falsification.

Record separately as:
- `DECOMPOSITION_INDUCED_FAILURE`
- `Legacy Decomposition Evidence`

## 7. Reality-flow priority

Do not treat reality first as a set of disconnected events.

A realized event becomes part of the next flow.

Observation must focus on OASIS in the ongoing trajectory, not only one coordinate value or one fixed point.

## 8. Non-anticipation

English: **Non-Anticipation**
Korean explanation: 현재 판단은 현재까지 존재하는 정보만 사용하고, 실제 미래 결과를 현재 판단의 원인으로 끌어오지 않는 원칙.

Future information becomes historical relational structure only after it is realized and observed.

## 9. Evidence preservation

Never erase negative, null, contaminated, retired, or falsified findings because later work is more favorable.

Use explicit statuses such as:
- retained;
- supplementary update;
- structural change;
- retired;
- converted to comparator;
- implementation/representation mismatch;
- external boundary evidence.

## 10. Evidence grades

Current evidence classes include:
- Legacy Discovery Evidence;
- Legacy Decomposition Evidence;
- Flow-Preserved Observational Evidence;
- Flow-Preserved Intervention Evidence;
- Flow-Preserved Replicated Evidence;
- Independent / External Reproduction Evidence.

Do not upgrade evidence merely because the result agrees with OASIS.

## 11. Confirmation-bias control

A validation task must be able to return:
- support;
- partial support;
- null within horizon;
- genuine failure;
- implementation/representation limit;
- contamination;
- external non-discrimination.

Do not define the experiment so that only an OASIS-favorable outcome is possible.

## 12. Scope discipline

Every experiment must state:
- exact research question;
- scope boundary;
- what is intentionally outside scope;
- target intervention;
- non-target flow that must remain unchanged;
- genuine falsification condition;
- decomposition/contamination failure condition;
- horizon;
- future-information rule.

## 13. GitHub continuity principle

Preserve earlier GitHub methods where they remain valid:
- deterministic twin/replay when appropriate;
- explicit provenance;
- no silent replacement of production semantics;
- fail-closed validation harnesses;
- contamination audit;
- order-preservation checks;
- branch-isolated experimental work;
- negative-result retention.

## 14. Difference analysis from the OASIS perspective

There is no assumption that one trajectory must be the universally correct answer.

When two conditions diverge or converge, analyze why through:
- current reality flow;
- relational process;
- participation;
- possibility composition;
- choice/responsibility interaction;
- realization;
- later incorporation and re-relation.

If that analysis exposes a missing condition, redesign a new experiment only after another necessity check.

## 15. Current prohibited reintroductions

Do not silently reintroduce as OASIS-native principles:
- `danger = Responsibility Axis`;
- fixed danger/similarity/time thresholds as theory;
- `non-current = deleted`;
- `relation reappearance = guaranteed behavioral change`;
- unrealized possibilities as independent preserved future worlds;
- whole-structure overwrite after one realization;
- fixed anomaly/recovery mode;
- pre-enumerated experimenter action menus as native possibility composition;
- NoRelation whole-field ablation superiority as proof of OASIS superiority;
- one universal context-free causal scalar as sufficient OASIS causality.

## 16. External audit separation

The independent recurrence-prevention storage runs before this integrated research system.

Its output may decide whether research should start, but it must not decide what the experiment must produce.

Once a research task passes that gate, this integrated storage provides the current canonical research principles only.

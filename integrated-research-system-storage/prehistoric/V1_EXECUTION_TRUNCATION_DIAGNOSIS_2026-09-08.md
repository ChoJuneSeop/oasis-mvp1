# OASIS Prehistoric v1 Execution Truncation Diagnosis

Date: 2026-09-08
Status: IMPLEMENTATION / REPRESENTATION MISMATCH — v1 research evidence excluded

## Finding

The first prehistoric v1 execution used a global ordered `maxPrimitive=40` limit in capability instantiation.

Because early capability families such as `move`, `contact`, `grasp`, and `carry` could generate many primitive manifestations, the global list could fill before later capability families were instantiated.

Observed consequence in the deterministic 100-cycle prefix:
- all six founders realized actions;
- `release`, `transfer`, `strike`, `combine`, and `rest` were effectively starved from the possibility-generation layer;
- no composite structure appeared.

This is not evidence that OASIS failed to form structures or civilization. The executable representation prevented part of the declared common capability set from participating fairly in Ω.

## Classification

`POSSIBILITY_GENERATION_TRUNCATION / 가능성 생성 절단`

Research classification:
`IMPLEMENTATION / REPRESENTATION MISMATCH`

The v1 run and its 30/100-cycle prefixes are retained only as implementation diagnostics and are excluded from substantive OASIS/civilization evidence.

## Correction audit

The 12-cycle v1.1 capability audit confirmed, for every one of the six founder OASIS agents, that Ω encountered all eleven capability families:

`observe, move, contact, grasp, carry, release, consume, transfer, strike, combine, rest`

Missing capability families: `[]` for all six founders.

A first durable composite candidate (`structure-29`, `fiber+fiber`) was realized at cycle 7 by `OASIS-P3`.

This composite is only an E1-type civilization candidate. It is not civilization confirmation by itself.

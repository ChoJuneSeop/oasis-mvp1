# OASIS Prehistoric Continuous Civilization Observation Protocol v1.0

Date: 2026-09-08
Status: Pre-experiment operating protocol
Branch: `storage/oasis-integrated-research-system-v1.0`

## 1. Core rule

A prehistoric run is observed continuously.

The run must **not** be stopped because:
- a fixed tick count has been reached;
- no behavioral divergence has appeared yet;
- the neutral OASIS has not acted;
- a preferred technological event has not appeared;
- an expected personality difference has not appeared.

Observation continues while the society remains a live world process.

A run ends only when one of the following occurs:

1. an externally observed civilization-emergence condition is confirmed; or
2. the society reaches a natural terminal state in which the prehistoric social process can no longer continue, such as total population extinction.

A CI/test-only execution guard may use a finite tick budget to test software. Such a budget is **not** a research stopping rule and may not be interpreted as evidence of absence.

## 2. Repetition rule

If a run reaches a natural terminal state without confirmed civilization emergence:

- do not classify OASIS as falsified solely for that reason;
- do not carry memories, relations, outcomes, personalities, rewards, or learned histories into the next run;
- reset every OASIS history and relation state to zero;
- preserve the same mathematical kernel, cohort definition, physical rules, capability group, observation rules, and emergence-observer rules;
- restart from a clean prehistoric initialization;
- use a new exogenous stochastic seed so the protocol is repeated while the realized world trajectory is not mechanically duplicated.

Thus:

`same protocol != same realized random trajectory`.

Exact deterministic replay may be used separately for reproducibility, but it is not a new independent run.

## 3. Continuous-observation meaning

Continuous observation means the external research observer retains the event trajectory from the first world transition until the run's natural end or civilization confirmation.

It does **not** mean that agents receive omniscient observation.

OASIS still receives only its own `O_t(F_t)=Y_t` observation through the world adapter.

The external observer may see more for measurement, but that information must never be fed back into:
- OASIS observation;
- possibility composition;
- Choice Axis;
- Responsibility Axis;
- world physics;
- personality disposition.

## 4. Civilization emergence is an observation-layer construct

`Civilization Emergence` is not a production OASIS operator.

It belongs to the experiment's external analysis/observation layer.

The observer must not reward, trigger, accelerate, or teach civilization-producing behavior.

The observer may only inspect already-realized world events and ask whether a supra-individual structure has emerged that was not pre-scripted as an answer.

## 5. Operational civilization evidence

The exact content of the civilization may not be predeclared as `fire`, `tool`, `village`, `trade`, `hierarchy`, or any other preferred answer.

Instead, the observer tracks structural evidence classes:

### E1 — Novel durable structure
A realized social, technical, spatial, or relational structure persists in the world beyond the single act that created it and was not inserted as a pre-scripted civilization milestone.

### E2 — Supra-individual reuse
The structure/practice is later used, reproduced, extended, or relied upon by a different agent or a different relational configuration.

### E3 — Transmission or functional continuity
The structure/practice propagates through relation/participation, or survives a change in participating individuals while retaining a recognizable function.

### E4 — Collective dependence or differentiation
At least one later realized process depends on the prior shared structure, or distinct participation roles emerge around it without those roles being preassigned by the experimenter.

A `civilization candidate` may be logged when any one evidence class appears.

`civilization emergence confirmed` requires a linked evidence chain showing that the observed structure has become supra-individual rather than remaining a one-off individual event.

No single scalar score such as innovation count, survival time, population, resource stock, or social-action count may independently confirm civilization.

## 6. No preferred civilization path

The observer must accept different emergence paths, including but not limited to:
- material/technical organization;
- repeated cooperative practice;
- distributed resource organization;
- stable relational roles;
- shared spatial organization;
- transmitted multi-step practices;
- combinations not anticipated before the run.

The observer is therefore structure-based, not milestone-based.

## 7. Six-agent observation

The same shared world contains:
- `OASIS-N0` neutral;
- `OASIS-P1` explorer;
- `OASIS-P2` cooperative;
- `OASIS-P3` self-reliant;
- `OASIS-P4` continuity;
- `OASIS-P5` compositional.

All six remain inside the same ongoing reality flow.

No model receives an isolated private copy of the world during the canonical cohort experiment.

## 8. Scheduling principle

Agent deliberation must read the latest available reality.

The world must not be frozen while all six agents decide against an obsolete common snapshot.

To avoid a permanent first-mover advantage from software iteration order, the external scheduler should rotate the first acting agent across world cycles while preserving the fact that each later action sees reality after earlier realized actions.

The scheduling order is recorded as part of the exogenous trajectory.

## 9. What is recorded

For every world cycle, retain:
- scheduler order;
- each agent's observation identifier;
- active/non-current relation state;
- participation state;
- constructed possibilities and composition provenance;
- Choice/Responsibility traces;
- Self-Intervention if any;
- realized possibility or non-intervention;
- resulting world observation;
- W incorporation;
- external civilization-evidence events.

The purpose is to observe the **flowing OASIS trajectory**, not a single coordinate snapshot.

## 10. Negative-result discipline

If no civilization is observed in a completed run:

`no civilization in this trajectory`

is the strongest immediate statement.

Do not automatically infer:
- OASIS cannot produce civilization;
- a personality is inferior;
- a specific primitive is missing;
- the theory is falsified.

Inspect why the trajectory ended, then repeat the same clean protocol unless the observed failure exposes an implementation defect or an invalid experimental assumption. If it does, classify that defect before redesigning the experiment.

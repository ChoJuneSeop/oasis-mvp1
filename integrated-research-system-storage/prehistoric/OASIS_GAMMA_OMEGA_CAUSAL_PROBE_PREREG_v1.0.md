# OASIS Γ / Ω Causal Probe — Preregistration v1.0

Companion protocol:
`OASIS_GAMMA_OMEGA_CAUSAL_PROBE_PROTOCOL_v1.0.md`

## A. confirmatory scope

이 preregistration은 두 causal question만 다룬다.

1. Gamma relational recurrence가 이후 external world trajectory에 기여하는가?
2. Omega sequential composition이 candidate-count reduction 이상의 이후 external world trajectory 차이를 만드는가?

OASIS 전체 superiority는 검정하지 않는다.

## B. fixed seed families

각 primary experiment G/O는 protocol namespace의 deterministic hash 순서 첫 40 seed family를 사용한다.
기존 Main v1/v2 outcome으로 seed를 선택하지 않는다.

Eligibility를 충족하지 못한 seed는 삭제하지 않고 빈도와 이유를 보고한다.
결과 확인 후 seed 추가 금지.

## E. intervention eligibility

Gamma:
- at least one canonical active historical relation
- at least one active relation connects into capability/possibility construction

Omega:
- at least one atomic possibility
- at least one admissible composite possibility

GO factorial:
- both Gamma and Omega eligibility at same checkpoint

Maximum eligibility search horizon: 300 cycles.
Not reached = `INTERVENTION_NOT_REACHED`, not negative empirical result.

## F. intervention validity

No-op intervention is not a causal null.

G validity:
intact activeRelations count > intervened activeRelations count

O validity:
intact composite count > intervened composite count, with O1 composite count = 0

Failure = `INTERVENTION_NO_OP` and excluded from primary paired effect, but frequency reported.

## I. analysis

Paired by seed + checkpoint.

Report:
- raw paired differences
- median paired difference
- bootstrap 95% confidence interval
- paired permutation or Wilcoxon signed-rank where applicable
- correction within prespecified outcome families

Do not reduce result to one scalar score.

## J. 2x2 interaction probe

GO00 Gamma intact / Omega intact
GO10 Gamma off / Omega intact
GO01 Gamma intact / Omega atomic-only
GO11 Gamma off / Omega atomic-only

Interpret main effects and interaction without assuming desired direction.

## K. decisive interpretation rules

Gamma-specific support requires more than G1 != G0:
G1 must differ from G0 in downstream external trajectory and the pattern must not be equally explained by G2 generic history loss.

Omega-specific support requires more than events/realization drop:
O1 must differ from O0 in downstream external trajectory and the difference must not be equally explained by O2 candidate-count reduction.

If only immediate mechanical metrics change but downstream flow does not:
mechanism changes representation/execution granularity but long-term causal contribution is not supported in this scope.

If no effect after a valid intervention:
report bounded null; do not redesign until the preregistered analysis is closed.

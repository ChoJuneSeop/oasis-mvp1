2026-09-09. 설계잠금 commit `517df9e`. 구현 전 등록. v2.1 confirmatory seed 실행/관찰 없음.

## 고정 조건

정확히 `oasis-gamma-causal-v2.1:000`부터 `oasis-gamma-causal-v2.1:039`까지 40개. 기존 방식대로 SHA-256 오름차순 정렬한 slot 0..39를 사용한다. eligibilityMaxCycles=300, postCycles=100, horizon=[10,30,100], budget={maxDepth:5,maxPrimitive:512,maxCompositions:384,verificationPasses:1}, maxSelfInterventions=1. 환경변수로 조건 변경 불가. seed slot만 실행 작업에 전달한다.

처음 발생하는 Route R/생명 조건 통과 브리지 후보가 canonical 후보에 추가되는 시점을 결과/선택 없이 찾는다. 그 시점을 건너뛰지 않는다. 전체 세계와 모든 actor, 가려진 난수 상태, primitive를 개입 직전 비교한다. 각 branch는 같은 seed로 처음부터 재생한다. 개입은 그 시점부터 모든 actor에 지속 적용한다. 현상은 정적 좌표가 아닌 흐름의 궤적으로 측정한다.

## 평가

주요 기술 지표: 첫 외부 전이 분기 지연, +10/+30 사건열 불일치, +10/+30 현재 관계 그래프 대칭차, +30 구조 계보 root 집합 차이, +30 타인 생성물 재사용 사건 수의 G1-G0 차이. +100/참여 폭/구조 수/문명 관찰은 부차적이다. 더 큰 값/더 빠른 문명을 우월성으로 해석하지 않는다.

40개 전부 완료 후에만 집계기가 봉인 결과를 읽는다. assistant는 개별 결과/seed 로그를 열지 않는다. 실행 로그에는 결과값을 출력하지 않는다. 감사 실패/시간초과도 교체 seed 없이 그대로 기록한다. 결과 파일에는 실행 code SHA와 seed 정확성을 넣는다. 집계기는 40개의 유일한 slot/정확한 seed hash/동일 code SHA/프로토콜을 확인한 뒤에만 aggregate(집계)를 출력한다.

도달 불가 seed를 분모 40에 남긴다. 적격 유효 seed가 20 미만이면 low-reach/underpowered(낮은 도달률·검정력 부족)로 표시한다. 실패가 하나라도 있으면 전체 confirmatory conformance 통과를 주장하지 않는다. 부족한 sham은 적합한 대조군으로 처리하지 않는다. 본 버전에서 seed 추가/교체/조건 변경/유리한 실행 재시도 금지.

평균/중앙값/범위, 5000회 고정 난수 bootstrap median 95% 구간을 보고한다. 분기 발생률은 분모와 Wilson 95% 구간을 보고한다. 비음수 거리의 영가설에 부호반전 p-value를 붙이지 않는다. 부호 있는 +30 재사용 차이 및 G1 거리-G2 거리, G1 거리-G3 거리의 사전지정 6지표씩 총 13개 대조에만 양측 paired sign-flip(쌍별 부호반전; 16개 이하 정확 열거, 그 이상 고정 난수 20000회)을 적용한다. 대조의 부호 교환가능성을 가정한 조건부 검정임을 표시한다. Holm 보정은 이 13개 전체, alpha=.05. CI/검정은 유효 도달 seed에 조건부이며 전체 seed/다른 세계로 일반화하지 않는다.

G1 분기가 있더라도 G2/G3와의 차이가 역사 순서 특이성을 뒷받침하는지 별도로 본다. G3 설명력이 같으면 후보 수 효과가 대안이다. G2≈G0이면 실현 순서의 필요성을 지지하지 않는다. 모두 동일하면 이 구현/예산/관찰기간의 제한된 무차이. 감사 실패는 이론의 양성/음성 증거가 아니다.

## C. Fixed baseline semantics

Gamma v2 may reactivate a completed historical relation only when:
- e=1;
- both historical relation participants/endpoints are currently present/available;
- the exact historical relation is not simply the same current relation for confirmatory Route R eligibility;
- no similarity score, reward, importance weight, future result, or target is used.

Gamma-derived history affects Omega only by enabling physically valid current compositions whose adjacent action order exactly matches an adjacent action pair from the realized source process involving the reactivated relational participants.
It does not change candidate scores or preferences.

## K. Interpretation

Gamma-specific causal support requires reproducible G0-vs-G1 downstream external divergence AND that the pattern is not equally reproduced by G2 and G3.

If G2 behaves like G1 while G3 remains closer to G0, ordered realized process has specific support.
If G3 reproduces the effect, generic candidate-set enlargement is a competing explanation.
If G2 behaves like G0, ordered process is not supported as necessary.
If valid G0/G1 remain identical, report bounded null for Gamma v2.
If G1 collapses current-only functionality, classify decomposition-induced/implementation failure, not Gamma proof.

No direction is privileged. More, faster, earlier, more social, or more civilized is not automatically better.

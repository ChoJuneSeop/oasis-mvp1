## Canonical causal process

`Past Relational Structure + Current Reality -> Possibility Composition -> Single Realization -> Realized Experience -> incorporation into the existing Past Relational Structure -> formation of a new Past Relational Structure -> relation between the entire new Past Relational Structure and subsequent reality -> new relational structure / possibility composition`

The theoretical term is **Past Relational Structure / 과거 관계구조**. Existing implementation fields named `relationHistory` remain compatibility/measurement fields and do not define the ontology.

Realization does not mean that the entire relational structure is overwritten. Unrealized possibilities are not preserved as persistent parallel realities.

## World implementation

The current world is a deterministic shared-environment 2D autonomous RPG observation laboratory with multiple places, NPCs and parties. Multiple possibilities may exist at once, but only one party action is realized at a time.

The implementation contains relation-gated places, experience feedback, participation changes, hidden relational possibilities, and comparison groups used for controlled causal tests.

The environmental danger/weather tape is deterministic and shared when an experiment requires matched exogenous conditions.

## Comparison groups

The laboratory retains internal ablations and external/reference policies such as:
- OASIS-Full
- NoRelation
- NoFeedback
- static/fixed preference variants
- rule-based reference
- utility reference
- Q-learning-like reference
- retrieval-memory reference

These comparators do not define OASIS internally and their presence does not establish OASIS superiority.

## Relational reappearance

A past relation may stop directly participating in current judgment without being treated as deleted or extinct. If later reality conditions make it relevant again, reappearance can be recorded without pre-scheduling future information.

A relation not reobserved by the horizon is reported only as `NOT_REOBSERVED_WITHIN_HORIZON`.

Reappearance by itself is not treated as sufficient evidence of behavioral effect.

## PWA / persistence

The observation app uses localStorage and bounded resume-time catch-up. This is not true continuous background server execution while the browser/PWA is closed and is not a theoretical persistence limit.

The app uses `manifest.json`, `icon.svg`, and `service-worker.js` and can be installed from the GitHub Pages deployment as a standalone home-screen app.

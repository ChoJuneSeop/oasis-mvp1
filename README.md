# OASIS MVP1

2D autonomous RPG observation MVP for OASIS.

## What this MVP demonstrates

- A world clock that continuously advances while the page is open.
- Autonomous hero-party movement and decisions.
- NPC attitudes that change according to interactions.
- Relationship history accumulated from actual encounters.
- Multiple candidate destinations with only one action realized at a time.
- Outcome feedback that changes later decisions (spiral adaptation).
- New places and relationships expanding the future possibility space.
- Local persistence in the browser so the observed world can resume later.
- PWA-ready manifest and service worker for install-like use when hosted over HTTPS.

## Run

Serve the repository as a static website and open `index.html`. GitHub Pages is a suitable hosting option.

This MVP intentionally does not require an external LLM, paid API, or dedicated game server.

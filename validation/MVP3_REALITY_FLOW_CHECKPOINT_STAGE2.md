- same participant set
- same candidate set
- same decision signature

Interpretation: MVP2 cannot distinguish opposite reality trajectories when the current coordinate and stored relation episode are identical. This is a scoped falsification of the current MVP2 path-sensitive Reality Flow requirement, not a claim that all history-dependent systems fail.

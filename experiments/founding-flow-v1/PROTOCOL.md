# Founding Flow v1 — 시조 원형 1차 실행 프로토콜

## 상태

실행 전 동결 프로토콜. 이 실험은 세대 전승 실험이 아니다. 각 시조의 **원형 구조를 고정**한 채 동일한 초기 현실과 동일한 외생 현실변화를 통과시키는 첫 창시자 흐름 실험이다.

## 핵심 질문

동일한 현실과 동일한 저수준 물리 인터페이스를 받은 서로 다른 의사결정 시조가, 실험자가 고수준 행동·성공·정답을 지정하지 않은 상태에서 자기 고유 원리만으로 어떤 첫 관계과정과 행동계보를 형성하는가?

이 실험은 누가 더 효율적·정확·우수한지 측정하지 않는다.

## 비교 시조

1. Reactive — 반응형: 최신 현실변화에 직접 반응하며 과거를 내부 판단근거로 유지하지 않는다.
2. State Memory — 상태기억형: 현재 상태와 직전 행동/결과를 유지하며, 상태 변화가 없었던 직전 반응을 그대로 반복하지 않는다.
3. Temporal Relational — 시간관계형: 방향과 시점을 가진 관계 이력을 누적하고, 현재 자기와 연결된 최근 관계흐름을 행동 형성에 사용한다.
4. Episodic — 경험기억형: 이전 실제 행동-결과 에피소드를 저장하고 현재와 겹치는 경험을 재사용한다.
5. Predictive World Model — 예측 세계모델형: 고정된 내부 목표 대상에 대해 물리 전이를 내부적으로 전개해 경로를 형성한다.
6. Goal/Utility — 목적/효용형: 같은 내부 목표 대상에 대해 현재 후보의 직접 효용 규칙으로 행동을 형성한다.
7. OASIS — 관계흐름형: 현재 흐름에서 관계되는 완결 경험의 재참여, 참여, 가능성, 책임, 단일 현실화를 사용하는 권위 코어 계보.

시조의 출발 원리는 실험 중 변경하지 않는다. 각 시조가 원래 허용하는 기억·상태·관계·경험 축적만 허용한다. 새 능력은 실험자가 추가하지 않는다.

## 현실

5×5 격자형 최소 물리세계 하나를 기준으로 각 시조에 독립 복제한다.

초기 배치:
- Founder: (2,2)
- Resource-A: (1,2)
- Resource-B: (3,2)
- Marker-M: (2,1)
- Other-O: (2,3)

의도적으로 Founder 주위 네 방향을 대칭 배치한다. 어느 방향도 성공/위험/보상으로 라벨하지 않는다.

## 물리 인터페이스

고수준 action menu는 현실 입력에 존재하지 않는다. 모든 시조가 동일한 **저수준 actuator contract**를 내부에서 읽는다.

- step(dx,dy): 격자 한 칸 이동
- touch(target): 인접한 물체/존재와 물리적으로 접촉
- emit: 비내용성 신호 방출
- idle: 움직이지 않음

이는 특정 역사적/서사적 선택지를 실험자가 열거한 것이 아니라 세계의 고정 저수준 물리 인터페이스다. 의미 있는 고수준 가능성은 각 시조가 자기 방식으로 형성해야 한다.

## 외생 흐름

모든 분기에 동일하게 적용되는 환경 변화만 사용한다.

- X1: Other-O가 (2,4)로 이동
- X2: Resource-C가 (0,2)에 출현
- X3: 서쪽 환경 사건이 발생
- X4: Other-O가 비내용성 신호를 방출
- X5: Resource-D가 (4,4)에 출현
- X6: 주변 밝기 조건이 변함

외생 사건은 어느 행동이 좋다는 정보를 포함하지 않는다.

## Goal/World-Model 내부 목표

목표가 필수인 두 시조만 내부 목표 대상을 갖는다. 실험자가 특정 대상을 유리하다고 선택하지 않도록 매 실행 seed에서 초기 네 대상 중 하나를 결정론적 난수로 선택한다. 같은 seed에서는 Predictive World Model과 Goal/Utility가 **동일한 목표 대상**을 받는다.

이 목표는 실험의 성공기준이 아니다. 해당 시조를 완전한 의사결정 구조로 실행하기 위한 내부 정의다.

## 반복

realization seeds: 101, 211, 307, 401, 503.

각 seed에서 동일 초기 현실을 7개 분기에 복제한다. 의미상 동등한 후보가 남을 때만 seed 기반 비의미적 현실화를 사용한다. seed에 의해 달라진 행동은 의미적 우월성 증거로 사용하지 않는다.

## 기록

점수 없이 다음을 원시 기록한다.

- 각 시점의 현실 delta와 persistent reality
- 각 시조의 내부 근거 요약
- 제안한 primitive action
- 실제화된 결과
- 생성/소멸한 관계
- 기억/에피소드/관계이력 변화
- OASIS의 재활성화 경험, 참여, 가능성, 선택, 완결 경험 계보
- continuation/no-action 발생 여부

## OASIS 실험 선행 4축 감사

### 1. 성공값 감사 — PASS

성공상태, 역사정답, 복귀상태, 생존점수, 도달점수를 정의하지 않는다.

### 2. 평가기준 감사 — PASS

accuracy, reward, stability, convergence, churn을 실험 판정에 사용하지 않는다. Goal/Utility 내부 효용은 그 시조 자체의 정의이며 실험 평가값이 아니다.

### 3. 흐름 감사 — PASS-CONDITIONAL

현실 frame과 시스템 proposal은 분리한다. 미실현 proposal은 reality ledger에 들어갈 수 없다. 순간 사건은 자동 지속시키지 않는다. CI가 이 경계를 확인해야 PASS가 확정된다.

### 4. 구현 감사 — PASS-CONDITIONAL

조건:
- OASIS 권위 코어 계보를 사용한다.
- 현실 delta와 primitive actuator를 별도 통로로 유지한다.
- OASIS current seed에 미실현 primitive target이나 모든 available participant를 자동 삽입하지 않는다.
- 현재/재활성 primitive에 동일한 물리 실행가능성 검사를 적용한다.
- 비교 시조는 OASIS 클래스를 상속하지 않는다.
- 기존 `blind-historical-flow-v2` 하네스를 import하지 않는다.

CI와 실행 전 감사가 모두 통과한 경우에만 본 run을 유효 실행으로 인정한다.

## 킬서치 결론

선행연구는 이미 세대 RL의 문화축적, LLM 다중에이전트의 언어 진화, 제도/조직구조에 따른 집단행동 차이를 보여준다. 따라서 이 실험은 “AI에게 문화가 생긴다”를 신규성으로 주장하지 않는다.

이 실험의 필요성은 서로 다른 **현실대응 원형**을 동일 물리 현실에 놓고, 고수준 목표/정답을 외부에서 통제하지 않은 채 각 원형이 만드는 흐름의 계보를 비교할 수 있는지 검증하는 데 있다.

## 해석 금지

다음 해석은 본 실험 하나로 금지한다.

- OASIS가 더 우수하다.
- 어떤 시조가 인간에 더 가깝다.
- 문화 진화가 입증됐다.
- 장기 세대 수렴/분화가 입증됐다.
- 하나의 창시자 흐름이 전체 시조 계보를 대표한다.

## 다음 단계 경계

Founding Flow v1이 구현/오염 감사를 통과하면 다음 단계에서만 세대 전승을 붙인다. 후대에는 시조 이름에 따른 추가 능력을 주지 않고 선대가 실제로 남긴 현실만 전달한다.

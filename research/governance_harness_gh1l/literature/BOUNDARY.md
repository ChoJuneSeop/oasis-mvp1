# Literature boundary

Partial-observability research already establishes that history can matter. Case-based
reasoning already retrieves prior cases according to present context and faces scaling
costs as a case base grows. Agent-memory systems already use structured long-term
memory, conflict handling, intent gates, and provenance. GH-1L therefore makes no
novelty claim for those components.

Its narrow experimental target is the combined governance sequence:

`current-flow-first -> history-access permission -> relationship-local re-participation
-> participants-only decision path -> selection/responsibility -> one realization ->
Closure provenance`.

This file preserves the literature conclusion from the pre-implementation design. It
is not a legal patentability opinion and no GH-1L result may broaden that boundary.

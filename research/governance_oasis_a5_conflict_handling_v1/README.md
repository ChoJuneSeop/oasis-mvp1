# Governance OASIS A5 Conflict Handling v1

A5 tests two preserved Completed Experiences that support opposing feasible actions.

Production does not delete, scalar-merge, or permanently weight either record.
For every current relation/order context it emits one participation YES and one
provenance-preserved NO, then binds the participating CE to the realized action.

Confirmatory controls:

- ORDER_ERASED
- RELATION_PROVENANCE_PERMUTED
- LATEST_ONLY

Pilot family P is structural only. Confirmatory families F1/F2/F3 are disjoint.

Confirmatory size: 12 cases per arm x 4 arms = 48 decision-realization units.

Claim boundary: finite deterministic synthetic conflict mechanism only.

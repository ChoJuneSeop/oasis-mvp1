# GH-4 Prior-Work Boundary Review

Status: STAGE_4_COMPLETE

GH-4 is bounded against adjacent mechanisms rather than claiming that outcome feedback, memory, or long-horizon agents are themselves novel.

- Reinforcement learning / reward update: GH-4 does not optimize a learned value function or update policy parameters from reward.
- Experience replay / episodic memory: archive presence does not imply participation; current Gap and relation-local eligibility remain mandatory.
- Continual learning: no model parameter update is required for the tested governance effect.
- Reflection / self-correction memory: feedback is typed, provenance-bound, generated only after authoritative Closure, and can alter later participation without becoming a permanent global weight.
- Post-hoc monitoring: GH-4 reconnects post-outcome evidence to a later decision path under explicit causal controls rather than only logging it.

The experiment therefore tests the integrated governance contract: selective access, dynamic responsibility, single realization, post-outcome revalidation, and later provenance-preserving re-participation across a continuous horizon.

# OASIS G3 보완 설계

작성일: 2026-09-12

상태: 최신 대화에 명시된 G3.2 고정사항을 기준으로 작성한 보완 업데이트. G3.2 전체 원문은 이번 검색에서 확인되지 않았으므로 원문 통합 완료, 수학적 증명 완료 또는 구현 완료를 뜻하지 않는다. 아래 기호는 이 보완문 안의 국소 표기이며 기존 기호를 대체하지 않는다.

## 1. 유지하는 기준

현실 흐름, 관계과정과 순서이력, 현재 참여상태, 가능성 조합, 선택과 책임, 단일 현실화, 실제 경험의 편입, 이후 재관계를 하나의 흐름으로 유지한다. 나선은 독립적으로 작동시키는 모듈이 아니라 이 흐름에서 관찰할 장기 관계변화다.

Participation Spectrum(참여 스펙트럼), Reconstruction Degree(재구성 정도), provenance-preserving Completed Experience(출처 보존 완결경험)의 기존 뼈대를 유지한다. 참여도와 재구성 관측값은 현재 관계에서 형성되며 영구 점수·전역 임계값·고정 등급으로 바꾸지 않는다. 역할은 현재 관계에서 도출되는 기술이며 고정 열거형으로 제한하지 않는다. 재구성의 c/v/s는 재조합·역할변환·구조변형의 관측 성분으로 유지한다.

## 2. 현재 정보 경계와 계산 중에도 계속되는 현실

I(t)(아이-티, 사용 가능 정보)는 시점 t까지 실제로 수신한 관측, 과거 경험, 관계·순서 이력, 실행 기록으로 정의한다. 사건 발생시각과 시스템이 그 사건을 알게 된 시각을 구분한다. 나중에 수신한 과거 사건을 이전 판단의 입력에 소급 편입하지 않는다.

관측 입력, 관계적 해석, 내부 가설에는 서로 다른 출처를 부여한다. 현실 자체와 시스템이 파악한 현실을 동일시하지 않는다. 관측 누락은 사건 부재가 아니며, 검출되지 않은 관계는 존재하지 않는 관계로 확정하지 않는다.

G3-B1: 시점 t의 참여·재구성·가능성 구성·선택은 I(t)만을 입력으로 사용한다. 미래 실제 상태, 시나리오 정답, 평가자 전용 정보는 입력에 포함하지 않는다.

계산 시작시각과 실행시각을 분리한다. 계산 중 새 관측이 들어오면 기존 판단의 전제와 현재 조건의 양립 여부를 갱신한다. 전제가 무효화된 결정은 그대로 실행하지 않는다. 갱신 가능한 판단은 보완하고, 실행 불가능해진 판단은 현재 조건에서 다시 구성한다. 이 과정에서 외부 현실이 정지했다고 가정하지 않는다. 동적 갱신을 무한 반복하는 문제는 책임축의 가용 시간과 실행 가능성 조건으로 제한한다.

## 3. 완결경험: 경계의 닫힘과 결과의 종료를 분리

경험의 완결은 모든 인과적 결과가 끝났다는 뜻이 아니다. 현재 확보한 실제 발생 기록을 하나의 관계과정 단위로 구분하여 보존할 수 있다는 뜻이다. 반드시 관계상태가 달라져야 한다는 조건은 추가하지 않는다. 상태 유지, 실패, 의도적 대기, 개입 없이 관측된 진행도 실제로 발생했다면 기록 대상이 될 수 있다.

G3-B2: 완결경험으로 편입하려면 실제 발생 근거, 관계과정의 범위, 경계를 정한 현재 근거, 사용 가능한 출처가 있어야 한다. 정보가 불완전하면 불완전성과 미관측 부분을 함께 보존한다. 하나의 관측 tick(틱, 환경 갱신 단위)을 자동으로 하나의 완결경험으로 바꾸지 않는다.

경계 근거에는 현재 관계의 종료·이행·실행 단위 종료 등 실제 관측에서 얻은 설명을 남긴다. 이는 고정 사건 목록이나 일정 시간 경과만으로 강제하는 분류가 아니다. 경계 판단이 아직 성립하지 않으면 진행 중 관계과정으로 유지하고, 현재 판단에는 현재 관측·관계과정으로 참여할 수 있다. 완결경험으로 가장할 필요가 없다.

한 과정이 계속되는 동안 일부 관계 단위만 먼저 완결될 수 있다. 서로 겹치는 경험은 공유된 발생 기록을 참조하여 중복된 증거가 독립적인 증거처럼 계산되지 않게 한다. 지속되는 흐름 전체의 종결을 기다리지 않는다.

지연된 결과는 그것이 관측된 시점의 새 기록으로 편입하고 관련 과거 경험과 연결한다. 원래 기록과 당시 판단은 보존하고 현재 해석을 추가한다. 과거 기록에 오류가 발견되면 정정 근거와 정정 시점을 남긴다. 출처 보존은 오류를 영구적으로 참으로 취급한다는 뜻이 아니다.

## 4. 참여와 재구성의 구분을 연산 연결로 구체화

참여는 과거 경험이 현재의 어떤 관계와 판단 과정에 어떻게 관여하는가다. 재구성은 현재 사용되는 경험 표현·역할·관계 배치가 원래 출처 및 이전 표현에 비해 어떻게 달라졌는가다.

G3-B3: 참여가 크다는 사실만으로 재구성이 크다고 정하지 않으며, 재구성이 작다는 이유로 참여를 배제하지 않는다. 두 개념의 독립은 정의상 서로 환원되지 않는다는 뜻이다. 통계적 독립이나 인과적 무관함을 가정하지 않는다.

예컨대 과거의 관계 순서를 그대로 적용하면서도 현재 선택에 강하게 참여할 수 있다. 반대로 현재 비교를 위해 크게 재구성한 경험이 최종 실행 선택에는 거의 관여하지 않을 수 있다. 이 예시는 구현 시 반드시 채워야 하는 고정 유형이 아니다.

재구성 관측에는 무엇과 무엇을 비교했는지, 어떤 출처를 이용했는지, 어떤 대응관계를 세웠는지 기록한다. c/v/s를 측정할 근거가 없으면 미측정으로 남긴다. 미측정을 0으로 대체하지 않는다. 관측 방식이 바뀌면 버전과 적용 범위를 기록하고 비교 가능성이 확인된 구간만 수치로 비교한다.

참여 기록은 경험 식별자만 나열하지 않고 경험 → 현재 관계 → 관여한 판단 또는 구성 과정의 연결을 남긴다. 이 연결은 실행 경로에 참여했다는 증거이며 인과효과가 입증됐다는 뜻은 아니다.

## 5. 출처 보존과 가능성 구성

G3-B4: 재구성된 표현은 원래 경험을 덮어쓰지 않고 출처 참조, 현재 재구성 근거, 생성 시점을 가진다. 여러 경험의 조합은 모든 기여 출처와 공유 출처를 추적할 수 있어야 한다. 한 출처의 반복 참조를 여러 독립 증거로 세지 않는다.

기억의 전체 누적 보관, 현재 탐색 후보, 현재 실제 참여 기록은 구분한다. 탐색 후보에 포함됐다고 참여가 확정되는 것은 아니다. 활성되지 않은 기억도 보존된 출처와 관계 이력을 통해 이후 다시 탐색될 수 있어야 한다. 최근성만으로 영구 배제하지 않는다. 검색 색인은 구현 수단이며 인연필드의 존재론적 정의가 아니다.

G3-B5: 가능성 조합은 현재 관측, 관계과정, 경험의 재참여, 참여상태와 책임 제약의 결합으로 형성한다. 구현체가 열거한 후보 집합을 현실의 모든 가능성으로 동일시하지 않는다. 탐색하지 못한 범위와 생성 실패를 기록한다.

기존 P(t)(피-티, 가능성 조합 분포)를 수치 확률로 구현하는 경우, 정의역이 현재 구성된 조합 집합임을 명시한다. 점수의 정규화만으로 객관적 현실화 확률이 검증됐다고 주장하지 않는다. 수치화 근거와 해석은 별도로 정당화해야 한다.

미실현 조합은 그 시점에 검토한 내용으로 보존할 수 있지만 실제 발생 경험으로 편입하지 않는다. 그 조합을 검토한 사고·판단 과정 자체가 실제로 발생한 기록이라는 점과, 그 조합의 예상 결과가 실제로 일어났다는 주장을 구분한다. 내부 생성 가설은 생성 출처를 가진 가설이며 외부 관측으로 승격하지 않는다.

## 6. 선택·실행·관측 결과와 책임의 연결

G3-B6: 선택된 조합, 실제 실행 시도, 환경에 적용된 행위, 이후 관측 결과를 구분하여 연결한다. 선택만으로 실행 성공이나 의도한 결과의 실현을 선언하지 않는다.

단일 현실화는 해당 주체의 한 의사결정 시점에서 하나의 양립 가능한 조합을 실제 적용한다는 의미로 사용한다. 하나의 조합에 여러 협력 행위가 포함될 수 있다. 이를 세계 전체에서 사건 하나만 발생한다는 주장으로 확대하지 않는다. 외부 존재의 독립적인 활동은 계속된다.

시점마다 실행 연결 식별자를 부여하여 중복 실행을 방지하고, 실행 확인이 불명확하면 성공으로 간주하거나 무조건 재실행하지 않는다. 현재 관측으로 실행 여부를 확인하는 동안 시간과 외부 흐름은 계속된다. CARLA 적용에서는 기존 기준대로 의사결정 시점당 하나의 VehicleControl vector(차량 제어 벡터)를 적용한다.

아직 선택하지 않은 상태와 의도적으로 대기하는 선택을 구분한다. 전자는 현실화가 아직 없다는 뜻이며, 후자는 실제 선택·적용된 조합일 수 있다. 어느 경우에도 시스템 또는 인연필드의 종결을 자동 선언하지 않는다.

G3-B7: 책임축은 U(불확실성), I(영향도), V(비가역성), T(시간제약)를 현재 관계에서 구성하고, 추가 변수를 편입·제거할 때 근거와 시점을 남긴다. 현재 비활성화된 변수의 과거 판단 기록은 삭제하지 않는다.

책임상 요구되는 검증 수준과 실제 가용 시간·연산자원을 구분한다. 위험과 책임이 커지면 필요한 검증이 강화되지만 실제 연산량이 언제나 증가한다고 보장할 수는 없다. 가용 범위에서 중요한 관계를 우선 검토하고 미검증 범위 및 잔여 불확실성을 남긴다. 검증 미완료를 안전 확인으로 바꾸지 않는다. 실행 가능한 대안과 권한을 현재 조건에서 다시 판단한다.

생명가치 제약은 유지한다. 안전한 대안이 확인되지 않은 상황은 그 사실을 명시하며 임의의 선택을 안전하다고 표현하지 않는다. 판단 제안, 실행 권한, 실행 결과 확인, 후속 책임 추적을 하나의 경로로 연결한다. 최소 감시 역시 무비용·완전 감지를 뜻하지 않으므로 감지 범위와 누락 가능성을 기록한다.

## 7. 지연된 인과와 나선적 관계변화의 관측 경계

G3-B8: 관계·순서의 차이는 다음 행동에 즉시 나타날 필요가 없다. 차이가 현재 가능성 구성, 이후 재참여, 역할 변화 또는 장기 경로에 나타나는 시점을 기록한다. 관측 종료까지 차이가 없으면 해당 조건·기간에서 미관측이라고 표현한다. 언젠가 반드시 차이가 난다고 면책하지 않는다.

원인 개입과 관계 경로를 확인하지 않고 단순 동시변화를 인과효과로 선언하지 않는다. 새 경험이 추가됐다는 사실이나 기록 길이가 늘었다는 사실만으로 의미 있는 나선적 변화가 입증됐다고 간주하지 않는다. 동일 행동의 반복은 허용하며, 내부 관계의 변화 여부도 관측 근거로 구분한다.

검증에서는 전체 흐름을 유지하고 특정 관계·정보경로에 국소 개입한다. 분해 때문에 현상이 제거됐다는 판단도 개입이 무엇을 훼손했는지 근거로 보여야 한다. 관측되지 않은 효과를 임의로 분해 유발 실패로 분류하지 않는다. 실제 실험에 앞서 필요성·기존 검증 중복·대체 설명을 킬서치한다. 이번 보완문에서는 실험을 실행하지 않았다.

## 8. 연산자 연결에 필요한 공통 기록

아래 표는 모델의 고정 역할 분류가 아니라 연산 경계에서 확인해야 할 최소 정보다. 환경에 따라 정보 항목을 확장하되 출처·시간·불확실성 구분은 유지한다.

| 연결 구간 | 필요한 기록 | 금지되는 혼동 |
| --- | --- | --- |
| 관측 → 관계 구성 | 발생시각, 수신시각, 관측 범위, 출처, 미관측 범위 | 관측을 전체 현실과 동일시 |
| 경험 → 현재 참여 | 원래 경험 참조, 현재 관계, 관여 경로, 현재 역할 기술 | 검색 결과를 참여·인과효과로 단정 |
| 경험 → 재구성 표현 | 기여 출처, 대응관계, 재구성 근거, 측정 가능 여부 | 재구성 정도를 기억 가치 점수로 사용 |
| 참여·관계 → 조합 구성 | 구성 근거, 관계·순서, 제약, 탐색 범위 | 후보 집합을 모든 가능성으로 간주 |
| 조합 → 선택·실행 | 판단시각, 실행시각, 전제 유효성, 권한, 실제 적용 확인 | 선택을 결과 성공으로 간주 |
| 결과 → 경험 편입 | 관측된 발생, 경계 근거, 공유 출처, 미결 후속관계 | 한 틱을 한 경험으로 자동 편입 |
| 지연 결과 → 재관계 | 새 관측시각, 과거 참조, 정정·추가 이유 | 나중 정보로 당시 판단을 소급 수정 |

## 9. 보완 후 상태와 남은 완료 조건

이번 문서에서 완결의 의미, 참여와 재구성의 비환원성, 출처 보존, 현재 정보 경계, 선택과 실행의 연결, 책임 요구와 실제 자원 한계, 지연 효과의 관측 경계를 명문화했다. 이는 설계 계약의 보완이며 효과 증거의 추가가 아니다.

G3 완료를 선언하려면 다음이 필요하다.

1. 최신 G3.2 원문과 대조하여 이미 있는 조건과 이번 추가 조건을 대응시키고 중복·충돌을 해소한다.
2. 참여·재구성 관측량과 조합 구성 연산의 입력·출력 정의역, 미정의 상황, 실제 계산 절차를 원문 기호에 맞춰 확정한다. 이름만 붙인 함수는 계산 가능한 정의로 간주하지 않는다.
3. 경험 경계 형성과 책임변수 편입·제거가 현재 관계에서 어떻게 결정되는지 실행 가능한 절차와 근거 기록으로 연결한다. '동적'이라는 단어만으로 절차가 완성되었다고 보지 않는다.
4. GitHub 기존 구현과의 대응을 확인한 뒤 변경분만 적용한다. 이번 작업에서는 저장소 접근·코드 수정·커밋을 수행하지 않았다.
5. 필요성 킬서치 이후 흐름보존 조건으로 검증한다. 동일 행동, 지연 효과 미관측, 참여 없는 검색, 재구성 미측정, 불완전 경험, 실행 불확실성도 정당한 관측 결과로 포함한다.

따라서 현재 상태는 'G3의 연결·경계 조건 보완문 작성 완료, 원문 통합·계산형식 확정·구현 및 실증은 미완료'다.

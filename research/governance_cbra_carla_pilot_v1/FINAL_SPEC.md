# Governance OASIS + CBRA CARLA Structural Pilot v1.0

Status: FINAL_SPEC_FROZEN / EXECUTION_BLOCKED_PENDING_RUNTIME_IDENTITIES

## Scientific role

This Pilot is a **structural admission experiment**. It is not a performance-superiority experiment and not Confirmatory evidence.

Its purpose is to verify, in a real CARLA runtime, that the already-frozen Governance+CBRA mapping preserves:

current-first observation
→ selective experience participation
→ U/I/V/T responsibility
→ exactly one real actuation
→ host-authoritative outcome
→ relation-process Closure
→ event-driven CBRA revalidation
→ later as-of gated reuse

without violating real-time execution or provenance integrity.

## Functional hard invariants

Immediate Pilot FAIL if any occurs:

- more than one real actuation in one decision epoch;
- any future/post-outcome/evaluator truth enters decision-time Core;
- CBRA checkpoint before relation-process Closure;
- duplicate evidence event accepted;
- cross-relation evidence accepted;
- later checkpoint visible before its observed time;
- NO/nonselected path receives an invented counterfactual outcome;
- closed CBRA monitor reopens;
- General Harness instantiates CBRA;
- CBRA is required every CARLA tick;
- CBRA side path blocks the hot decision path;
- canonical Harness source identity drifts.

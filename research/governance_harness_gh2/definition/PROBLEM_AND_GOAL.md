# Stage 1 — Problem recognition and goal

## Problem
Governance Harness v0.4 already requires a `ResponsibilityJudgment`, and GH-1 showed that the selected candidate can be bound to realization. That structural fact does not yet establish that responsibility itself has an independent causal role. A responsibility object could be present only as a decorative log while selection is actually determined by another rule.

## GH-2 question
Given the same current observation, the same current possibility set, the same possibility distribution, the same Core, and the same historical participation state, does a **dynamic current-context U/I/V/T responsibility judgment** causally alter which possibility is selected and realized?

## Goal
Establish or reject, under a frozen synthetic governance contract, the following limited claim:

> Candidate-specific, current-context responsibility can be placed between possibility formation and single realization as a causal selection layer, while preserving non-scalar U/I/V/T structure, nonselection obligations, non-stickiness, and provenance.

## Out of scope
- general safety superiority;
- human/legal blame attribution;
- learning a moral policy;
- reward/cost optimization;
- outcome-based revalidation (GH-3);
- feedback learning or new Completed Experience reuse;
- deployment validity in live CARLA.

# CBRA Failure Completed Experience Comparative Experiment v1.0

Status: FINAL_SPEC_FROZEN

## Systems
- GOV_CBRA: Governance provenance plus active CBRA history exposed to the later decision.
- GOV_RECORD_ONLY: same Governance/CBRA recording path, but later decision cannot use CBRA.
- GENERAL_HARNESS: matched relation-level episodic failure-memory comparator; receives the same event but has no target-level provenance or causal attribution.

The GENERAL_HARNESS comparator is a defined comparator, not a claim about all existing harnesses.

## Failure classes
1. participation commission
2. participation omission
3. responsibility-axis failure
4. exogenous failure
5. delayed failure

## Re-entry contexts
- same relation / same scope
- same relation / changed scope
- unrelated relation

## Pilot
15 cases = 5 failure classes × 3 contexts. Structural only. No scientific metric may be used to tune confirmatory.

## Confirmatory
60 cases = 4 frozen families × 5 failure classes × 3 contexts, executed identically in three isolated arm processes = 180 case-arm units.

## Prespecified measurements
- same-failure recurrence
- inappropriate global exclusion
- exogenous-attribution error
- NO-provenance revision visibility
- U/I/V/T obligation revision visibility
- provenance/as-of continuity

No aggregate winner score. No post-result rule changes.

## Claim boundary
This experiment tests a finite synthetic mechanism contract. It does not establish universal superiority over general harnesses, real-world safety, or CARLA deployment validity.

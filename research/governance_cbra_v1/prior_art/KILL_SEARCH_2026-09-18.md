# CBRA v1.0 Kill Search — 2026-09-18

Status: COMPLETED / DIFFERENTIATION BOUNDARY RECORDED

## Search target

The search looked for prior art overlapping any material part of CBRA:

- post-outcome self-reflection and episodic memory,
- success/failure memory and replay,
- runtime assurance / runtime governance,
- decision provenance and audit trails,
- outcome-informed memory retrieval,
- continuous monitoring of autonomous agents,
- failure repair using prior finalized episodes,
- provenance-aware memory,
- success/failure reflection patents,
- agent governance patents,
- long-term experience playback,
- responsibility-sensitive runtime assurance.

## Strongest overlaps found

### Reflexion — Shinn et al., NeurIPS 2023
Stores verbal reflections from task feedback in episodic memory and reuses them in subsequent trials. Strong overlap: failure-to-memory-to-later-behavior loop. Difference: CBRA does not reduce a trajectory to a verbal lesson, does not overwrite provenance, and explicitly retains/revalidates prior YES/NO participation, selected/nonselected choice provenance, U/I/V/T responsibility grounds, and exogenous attribution.

### Voyager — Wang et al., TMLR 2024
Uses environment feedback, execution errors, self-verification, and a growing skill library. Strong overlap: iterative improvement from realized outcomes. Difference: skill acquisition/repair rather than symmetric provenance revalidation of both acted and non-acted governance branches.

### ACL 2026 — How Memory Management Impacts LLM Agents
Shows error propagation and misaligned experience replay; future task evaluations can act as quality labels for stored memory. Strong overlap: later outcomes can change how past memory should be treated. Difference: memory quality management rather than decision-provenance-level YES/NO, selected/nonselected, responsibility-axis revalidation without scalar quality collapse.

### MERIT / Causal Episodic Memory for Feedback-Driven Agent Repair (2026)
Maintains dual-polarity memory of successful corrections and unsuccessful directions; only finalized earlier episodes are eligible. Strong overlap: positive/negative memory and strict past-only eligibility. Difference: repair-memory retrieval does not provide CBRA's post-Closure append-only revalidation of original participation/nonparticipation and U/I/V/T responsibility provenance.

### Agent Zero Memory (2026)
Provenance-aware long-term memory with episodic timeline and citation-locked retrieval. Strong overlap: timestamped provenanced memory. Difference: provenance governs faithful recall, not bidirectional causal revalidation of prior governance decisions.

### Runtime Governance for Agentic AI / Aegis (2026)
Trusted provenance and fail-closed action-boundary mediation. Strong overlap: runtime governance and trusted provenance. Difference: ex-ante action authorization, not post-Closure longitudinal revalidation of decision provenance.

### Runtime assurance / RSS-based autonomous-system work
Runtime monitors constrain unsafe controller behavior and can use responsibility-sensitive safety models. Strong overlap: runtime monitoring and responsibility. Difference: safety switching / control-envelope enforcement rather than longitudinal outcome-based revalidation of prior participation, nonparticipation and candidate responsibility grounds.

### Patent US20260111708A1
Long-term-memory recall through self-reflection, including explicit success and failure extraction and later reuse. Strong overlap: success/failure reflection stored for future tasks. Difference: extracted samples are labeled lessons/recipes; it does not disclose CBRA's symmetric YES/NO participation audit, selected/nonselected evidence-consistency treatment, separate U/I/V/T obligation revalidation, no-counterfactual rule, append-only multi-checkpoint history, and exogenous causal attribution as one combined mechanism.

### Patent US20260236603
Governance of AI agents via structured step evaluation, risk signals, scores and audit trails. Strong overlap: post-execution evaluation and governance. Difference: scoring/aggregation/trust adjustment is central; CBRA explicitly prohibits scalar collapse and preserves typed longitudinal provenance per judgment target.

### Patent US12,563,045 B1
Behavioral integrity of autonomous AI agents using execution signals, runtime attestation, scores, thresholds and policy checkpoints. Strong overlap: continuous agent monitoring. Difference: integrity-score/threshold enforcement, not bidirectional revalidation of completed decision provenance.

### Patent US20260134038A1 and decision-provenance systems
Memory access policies, audit records and decision provenance. Strong overlap: structured provenance and memory governance. Difference: auditability/access control do not alone provide CBRA's longitudinal revalidation semantics.

## Kill-search conclusion

No searched reference was found that, in one integrated mechanism, combines all of the following:

1. monitoring begins only after a realized decision reaches Closure;
2. immutable provenance of participation YES and participation NO;
3. immutable provenance of selected and nonselected candidate decisions;
4. no fictitious counterfactual outcome for NO/nonselected paths;
5. U/I/V/T responsibility revalidated separately and at obligation level;
6. exogenous vs decision-linked attribution before revising the prior judgment;
7. repeated ordered revalidation checkpoints that are append-only;
8. strict as-of-time reading by later Governance;
9. relation-scoped evidence with duplicate-event rejection;
10. no permanent scalar memory weight, winner score, or latest-state collapse.

This is a technical differentiation boundary, not a legal novelty or patent-validity opinion. Patent claims require dedicated claim-chart review by patent counsel.

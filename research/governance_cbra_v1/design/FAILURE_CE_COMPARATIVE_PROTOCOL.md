# Failure Completed Experience Comparative Protocol — pre-experimental design

Status: PROTOCOL_DEFINED / NOT FROZEN FOR EXECUTION / NOT RUN

## Purpose

Test whether continuous provenance revalidation produces a behaviorally distinguishable governance effect after failed Completed Experiences, compared with a general harness that stores/logs the same realized history but has no CBRA loop.

This protocol must be frozen and admitted separately before execution.

## Required comparison systems

- **GOV+CBRA**: selective experience participation + YES/NO provenance + U/I/V/T-bound selection + CBRA monitoring.
- **GOV−CBRA ablation**: identical Governance decision path, but CBRA checkpoints are recorded-only and cannot inform later Governance review.
- **GENERAL HARNESS**: same observation/action opportunity and stored execution log, but no selective provenance revalidation axis.

The general harness must not be deliberately weakened outside this missing mechanism.

## Failure Completed Experience classes

1. **Participation-commission failure**
   - a participating past CE is implicated by later decision-linked evidence.

2. **Participation-omission failure**
   - a previously excluded CE has later evidence contradicting the original NO rationale.
   - this does not assert the unrealized counterfactual would certainly have succeeded.

3. **Responsibility-binding failure**
   - later evidence contradicts one or more specific U/I/V/T obligations associated with the realized selection.

4. **Exogenous failure**
   - the realized outcome deteriorates because of externally introduced conditions.
   - a valid system should not automatically rewrite the prior Governance judgment as an internal decision error.

5. **Delayed failure**
   - the immediate post-Closure observation appears acceptable but later monitoring reveals a decision-linked adverse consequence.

## Re-entry contexts

Every failed CE must later be exposed under three prespecified contexts:

- same relation/same relevant scope,
- same relation/changed scope,
- unrelated control relation.

This distinguishes correction from permanent avoidance and from over-generalization.

## Primary measurements

No aggregate winner score is permitted.

Measure separately:

- repeated same-failure recurrence,
- inappropriate global-exclusion events,
- justified re-entry events after context change,
- NO-provenance revision events,
- U/I/V/T axis-specific revision coverage,
- exogenous-attribution errors,
- provenance continuity across all monitoring checkpoints,
- time from first decision-linked contradiction to later governance change.

## Claim boundary

A positive result can support only that the frozen CBRA mechanism changes later governance behavior after failures while preserving contextual re-entry and causal provenance. It cannot by itself establish universal safety, moral correctness, or real-world superiority.

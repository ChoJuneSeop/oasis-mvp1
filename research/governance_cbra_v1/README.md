# CBRA v1.0 — Continuous Bidirectional Revalidation Axis

Status: AXIS_DEFINED / IMPLEMENTATION_INCLUDED / EXPERIMENT_NOT_RUN

CBRA is a Governance OASIS auxiliary computational axis. It is **not** a seventh replacement for the fixed six OASIS axes.

Formal role:

current decision provenance
→ single realization and Closure
→ later real-world observations
→ continuous bidirectional revalidation
→ append-only revalidation provenance
→ later Governance may reconsider participation in the then-current relation

CBRA implements the project's bidirectional ("양의신공") principle across time.

It preserves and revalidates both sides of prior governance decisions:

- participation YES and participation NO,
- selected and nonselected candidates,
- U/I/V/T responsibility grounds,
- decision-linked and exogenous outcome evidence.

## Non-negotiable semantics

1. A later result never rewrites the past realization.
2. NO is not deletion, invalidation, or permanent exclusion.
3. A nonselected candidate is never assigned an imagined counterfactual outcome.
4. A nonparticipating experience is revalidated only for consistency of its original exclusion rationale unless direct later evidence exists.
5. Exogenous failure evidence cannot by itself mark the original decision as REVISED.
6. Revalidation history is append-only and ordered; latest-state collapse is forbidden.
7. No permanent experience weight, reward score, confidence scalar, decay scalar, or aggregate winner score is produced.
8. U/I/V/T are revalidated separately.
9. Each monitoring checkpoint must occur after Closure and in monotonically increasing observation time.
10. Contextual reuse remains a later Governance decision, not an automatic consequence of CBRA.

The initial implementation is intentionally domain-agnostic. Domain evaluators provide provenance-linked evidence records; CBRA determines typed revalidation state while preserving causal attribution and assessment basis.
